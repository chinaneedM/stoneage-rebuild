# Research

This directory holds structured historical and technical research.

- `origin/` — JSS-era concept, launch, world, people, pets, systems.
- `clients/` — client versions, binaries metadata, hashes, resource layouts, diffs.
- `sources/` — source-specific notes and archival metadata.
- `evolution/` — controlled version/feature evolution comparisons.
- `mechanics/` — reconstructed gameplay/runtime mechanics with explicit evidence grades.
- `recovered/` — derived reports from recovered bytes; proprietary payloads are not stored here.
