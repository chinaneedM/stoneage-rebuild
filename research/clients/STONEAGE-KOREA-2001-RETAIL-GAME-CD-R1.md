# StoneAge Korea 2001 Retail Game-CD Recovery R1

Date: 2026-09-19

## Purpose

Track the independently attested **mass-distributed Korean retail/package StoneAge game CD** as a public-preservation recovery target distinct from:

- the 2000–2002 operator/portal download mirrors;
- the 2001 GameTime Perfect Guide bonus CD;
- later Netmarble-era client media.

This is a recovery target, not proof that a publicly downloadable disc image currently exists.

## Contemporary evidence

### DailyGame / Daily eSports — 2000-10-27

Sources:

- https://www.dailygame.co.kr/view.php?ud=200010271416380001837_26
- syndicated copy: https://www.dailyesports.com/view.php?ud=200010271416380001837_26

The contemporary product-presentation report states that Inium had signed a supply contract with Samsung PC-education-center operator **Mentec (`멘테크`) for roughly 60,000 sale packages (`판매용 패키지`)** and planned nationwide retail distribution through **Yongsan PC-game wholesalers**.

This materially upgrades the physical-media branch:

- the package channel is attested already in **October 2000**, during the original Korean trial/distribution period;
- the planned volume is mass-market scale rather than an isolated promotional disc;
- the distribution path is explicitly tied to Yongsan wholesalers and nationwide PC-game shops.

Evidence class:

- **FACT / contemporary industry-press evidence of a 60,000-unit retail-package supply contract.**

Open fields:

- whether all contracted units were manufactured/shipped;
- package SKU/catalog number;
- package price;
- outer-box artwork;
- CD label/matrix code;
- exact client build and installer filename;
- relationship between this package disc and portal-distributed clients.

### Electronic Times — 2001-05-04

Source:

- https://www.etnews.com/200104300317

The article recommends StoneAge as an online game for children and states that users could buy a **game CD in Yongsan and similar retail locations**, with a **two-month free-use coupon** included.

This directly establishes a separately sold Korean StoneAge game-CD/package channel by early May 2001.

Evidence class:

- **FACT / contemporary press evidence of retail game-CD distribution.**

What it does not establish:

- package publisher/catalog number;
- exact CD label;
- disc count;
- client version/build;
- installer filename;
- disc filesystem;
- checksum;
- whether the included client equals Hananet/CNET/GameTime copies.

### GameMeca — 2001-07-09

Source:

- https://www.gamemeca.com/view.php?gid=3718

The article reports Inium membership statistics after commercial service and explicitly says the registered total included:

- paid members;
- trial-version registrants;
- **package purchasers (`패키지 구입자`)**.

This independently confirms a package-purchase channel within the Korean Inium-era user population.

Evidence class:

- **FACT / contemporary industry-press evidence of package purchasers.**

## Relationship to the GameTime Perfect Guide CD

The GameTime `스톤에이지 퍼펙트 가이드` is separately documented as a 2001 book with one 12cm compact disc containing a StoneAge installation program plus demo-game content.

Do not merge the two media objects without artifact-level evidence.

Current working distinction:

1. **Retail/package StoneAge game CD**
   - sold through Yongsan and similar retail channels;
   - associated with a two-month free-use coupon;
   - package purchasers counted by Inium in membership statistics.

2. **GameTime Perfect Guide bonus CD**
   - bundled with a 318-page guide;
   - bibliographically documented as one 12cm compact disc;
   - retailer description says it contains the StoneAge installation program plus demo-game content.

The contents could overlap, but equality is OPEN.

## Recovery value

This target is operationally important because a physical game CD may preserve:

- an operator-era installer independent of dead portal mirrors;
- exact original filenames and directory structure;
- volume label and mastering metadata;
- installer timestamps;
- bundled DirectX/runtime components;
- subscription/coupon artifacts that date the media;
- possibly a client state closer to the 2000–2001 Korean commercial baseline.

A public disc dump, preservation catalog entry, checksum record, disc-label photograph, or complete file tree would materially advance Phase 0.
