# StoneAge 2.0 — CHIP 新电脑 November 2001 carrier lead R1

Date: 2026-09-25

## Summary

A preserved full-text scan of **《大众软件》2001 年 11 月 B / 2001 第 22 期** contains a StoneAge 2.0 upgrade notice that expands the known magazine/disc carrier list for the Mainland 2.0 complete-upgrade client.

The project previously used the surviving 17173 upgrade guide, which names 13 magazine/book/disc carrier identities. The preserved Popsoft text independently includes the same distribution context but additionally lists:

- **《CHIP 新电脑》11 月号**

This is therefore a new exact carrier identity for the active 2001-11-02 client-recovery track.

## Source

Internet Archive preserved full text:

- item family: `popsoft-magazine_202403`
- issue path: `2001/大众软件-2001年11月B_djvu.txt`
- public text URL:
  `https://archive.org/stream/popsoft-magazine_202403/2001/%E5%A4%A7%E4%BC%97%E8%BD%AF%E4%BB%B6-2001%E5%B9%B411%E6%9C%88B_djvu.txt`

Relevant text region states that users who already owned StoneAge 1.X could obtain the StoneAge 2.0 complete upgrade through listed magazines/media. The preserved list includes the previously known carriers and, between `《游戏原动力》11月号` and the two StoneAge guide books, explicitly includes `《CHIP 新电脑》11月号`.

The same preserved issue also contains a correction concerning `《晶合秘藏Ⅱ之红宝石》`: the bundled StoneAge 2.0 media should be understood as an **upgrade version**, not the formally activated retail version. This reinforces the need to distinguish "complete upgrade client bytes" from product activation/serial entitlement.

## Evidence classification

### FACT

- The preserved Popsoft issue text contains `《CHIP 新电脑》11月号` in a list of media through which users could obtain the StoneAge 2.0 complete upgrade.
- This carrier does not appear in the currently preserved 17173 version of the same distribution list.
- The Popsoft issue is contemporaneous to the November 2001 transition context.

### OPEN

- Whether the CHIP disc itself survives in a public preservation collection.
- Exact disc title/volume label/catalogue identity.
- Whether the bundled file is named `stoneage2.0setup.exe` or uses another filename/path.
- Whether the bundled client is byte-identical to the Sina-labelled package.
- Exact optical-disc filesystem, file hashes and package provenance.

## Operational consequence

Add `《CHIP 新电脑》11月号` as a new carrier-search token for the StoneAge 2.0 client-recovery queue.

Search at the **carrier/filesystem level**, not only by the Sina filename, because magazine discs may rename, wrap or directory-nest the upgrade package.

Do not collapse the Popsoft and 17173 lists into one "official" list without preserving the source difference. Treat the extra CHIP carrier as an independently preserved contemporaneous distribution clue.
