# JSS Retail Package Photo Evidence — R1

Date: 2026-09-18

Purpose: evaluate newly recoverable photographs of an early Japanese `STONEAGE` package against the project's first-party JSS manual and contemporaneous launch advertising.

This note does **not** promote a community collector caption to first-party fact. It separates visible artifact evidence from later narrative claims.

## 1. Question being tested

The current project model has been:

- FACT: the normal JSS retail install used a StoneAge **game CD**;
- FACT: contemporaneous launch advertising promoted an initial-edition `STONEAGE` **bonus/special CD**;
- OPEN: whether the bonus CD was physically distinct from the game/install CD, and what either disc contained.

The highest-priority physical-media question was therefore whether any surviving package photograph could show the two media objects separately.

## 2. Newly recoverable collector-photo set

Source record: `SRC-JP-1999-RETAIL-COLLECTOR-PHOTO-01` in `docs/SOURCE-REGISTRY-PHYSICAL-MEDIA-R1.md`.

- early JSS contents spread: `https://www.shiqi.club/zb_users/upload/2020/08/20200804212101_44867.jpg`
- launch advertisement reproduced with the article: `https://www.shiqi.club/zb_users/upload/2020/08/20200804212102_40031.jpg`

### Visible observations

The package photograph depicts:

- a `STONEAGE` Windows 95/98 box using the early JSS/Gamer's Dream artwork;
- a matching printed manual;
- one illustrated StoneAge optical disc in a jewel case;
- a second physically separate optical disc with a yellow/blue label design;
- several registration/service-related paper items.

The associated advertisement image visibly states an initial-edition `STONEAGE` bonus CD and a 5,000-copy limitation.

This is the first currently accessible photo set in the project that visibly places **two distinct optical discs** beside the early JSS retail box/manual.

## 3. Evidence triangulation

### A. First-party JSS manual — high confidence

`SRC-JP-JSS-STONEAGE-MANUAL-ARCHIVE-01` establishes that normal installation began from a StoneAge **game CD**, that DirectX 6.1 was on that disc, and that the package also used a physical CD NUMBER card for service registration.

This proves a normal game/install disc class existed.

### B. Contemporaneous retail advertisement — high confidence for printed claim

`SRC-JP-1999-AD-YAHOO-01` visibly advertises an initial-edition `STONEAGE` bonus/special CD.

This proves that a bonus-CD offer was part of the 1999 launch marketing, but by itself did not prove whether that CD was separate from the game disc.

### C. Later collector photography — lower provenance, direct visual value

`SRC-JP-1999-RETAIL-COLLECTOR-PHOTO-01` depicts two separate discs alongside the early JSS box/manual.

The photograph is later community preservation and lacks a project-controlled chain of custody. It therefore cannot become S-grade package proof on its own. It does, however, directly answer the visual question that the earlier sources could not: the photographed early-package set contains two separate optical media objects.

### D. Surviving sealed-package marketplace lead

`SRC-JP-1999-RETAIL-MERCARI-01` independently describes an unopened JSS `STONEAGE 初回限定版` and states that it contains a bonus CD-ROM.

The listing remains a seller claim until direct inspection; its value is independent corroboration of the collector-photo interpretation.

## 4. Working conclusion

### HYPOTHESIS — strongly corroborated, not S-grade

The best current model is now:

> The 1999 JSS initial-edition package likely contained a normal game/install CD **and** a physically separate bonus/special CD.

This model is supported by mutually complementary evidence:

- first-party manual -> game CD;
- contemporaneous advertisement -> bonus CD;
- later physical-package photo -> two separate discs;
- sealed-package seller description -> bonus CD included in an initial limited edition.

The model should still **not** be promoted to an unqualified FACT about every 1999 package until the project directly inspects an original package or obtains equivalent provenance-preserving primary evidence.

## 5. Important source correction: the article's second package is not JSS

The same collector article describes two Japanese packages in language that implies both were JSS-issued. The photographs contradict that wording for the second package.

Visible second-package evidence shows:

- `BOTHTEC` branding;
- DigiPark branding;
- Windows 98SE/Me/2000/XP support;
- product code `WR-04156`;
- barcode `4988609011565`.

Therefore that second package belongs to the later Japanese revival lineage and must **not** be used to infer 1999 JSS packaging, disc count, CDK format or client state.

This source-quality defect is useful: it demonstrates why artifact-level visual classification must override broad community captions when the two conflict.

## 6. What remains unresolved

For the **1999 JSS package**, still recover:

- high-resolution front/back/side box photographs;
- product/JAN code;
- both disc face labels at readable resolution;
- disc matrix / mastering identifiers and, if present, IFPI codes;
- exact CD NUMBER card format;
- manual/inserts completeness;
- whether the yellow/blue disc is explicitly labeled `bonus`, `special`, audio, data, or hybrid;
- track/session layout for the bonus disc;
- filesystem tree and hashes for the game disc;
- retail `stoneage.exe` file size/hash/PE metadata;
- any `sa.exe`, update config, manifest or `data\download` seed material on the retail disc.

## 7. Next search strategy

1. Search for the exact first-package artwork plus `初回限定版`, `ボーナスCD`, `JAPAN SYSTEM SUPPLY`, `Windows95/98`, and the 1999-10-15 date.
2. Prioritize collector/seller pages that expose **back-box and disc-face photographs**, not merely front-box thumbnails.
3. Try to locate the owner/original upload behind the 2020 collector-photo chain and ask only for provenance-preserving metadata if contact becomes possible; do not assume the repost narrative is accurate.
4. Continue tracking the sealed Mercari package image set; the current web retrieval path exposes the listing but not all 13 original image bodies.
5. If an original package becomes obtainable, photograph labels/matrix codes before imaging any media, then image outside the repository and record hashes/metadata only.

## 8. Effect on Phase 0 priority

This finding narrows, but does not close, the top blocker.

Before this pass, the project lacked direct visual evidence that the launch-era game CD and advertised bonus CD were separate physical discs. We now have a lower-provenance collector photo depicting exactly that arrangement.

The priority therefore shifts from merely proving that a second optical disc probably existed to obtaining **S-grade identification of both discs** and recovering the actual game-disc bytes/file tree with provenance.
