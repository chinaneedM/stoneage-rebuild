`STONEAGE-TW10-GAMEPLAY-SCHEMA-R1.json`、原版回调源码派生指纹`STONEAGE-TW10-GAMEPLAY-CALLBACKS-R1.txt`及原台湾1.0原光盘ADRN数据不是后代游戏建模。原回调定位：
