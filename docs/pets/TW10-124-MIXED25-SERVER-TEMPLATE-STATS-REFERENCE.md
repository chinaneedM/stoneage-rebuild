## 读数规则

1. 基础四数是后期服务端`BASEVITAL / BASESTR / BASETGH / BASEDEX`配置字面值，**不是宠物出生时的HP／攻击／防御／敏捷**，也不是已证的最小最大区间。

2. 元素是后期配置第16–19列地／水／火／风字面量；INITNUM、LVUP是第8/9列字面量，不把`4.50`认成台湾1.0官方成长率。

3. `PETFLG`仅是后期模板开关列，七个技能槽只提供静态技能ID；不能把它们写为台湾1.0原服自带技能、抓捕资格或原生运行效果。

4. 后代服务器确实有[成长随机分档与升级模型](../../research/mechanics/STONEAGE-PET-GROWTH-CORE-R1.md)，但未证明它与这份混合2.5或台湾1.0原服算法完全相同。
