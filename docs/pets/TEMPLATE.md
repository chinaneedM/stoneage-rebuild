# 每只宠物统一复原档案模板 R1

**目标**：把宠物历史考据结果转成可逐只查看、逐项补证的档案。模板不是虚构默认数值：**没有同版证据，一律“未知”**，空值与0不同。

## 一、基础身份

| 字段 | 每只都必须保留的内容 |
| --- | --- |
| 唯一档案键 | 以地区+版本+客户端候选来源键命名，**不要冒充官方Pet ID** |
| 所属地区 / 版本 / 日期 | 原始官方经典PC谱系；发表日期与本地客户端版别要分开 |
| 原客户端名及原文别名 | 台湾繁体/大陆简体/日文/韩文原字形分别保存 |
| 官方原服务器宠物ID | 未得到同服主档时为空，不能用SPR图号填充 |
| 证据强度和重复关系 | 客户端本地、运营原公告、已证实实服、跨版同图候选分别标注 |

## 二、图鉴与原资源

| 字段 | 内容 |
| --- | --- |
| 原2D图形/“模型” | 原SPR组号/图号/完整段SHA；**不要要求原石器3D模型** |
| 原头像/图鉴图 | 原RD、图形别名、尺寸、源SHA；私有原图只在私人预览 |
| 动作与方向 | 动作原码、方向原码、原帧序号、每序列帧数、源持续字段、缺帧状态 |
| 图鉴描述与生态 | 仅填写原版有文字来源的生物故事、栖息区域与分系 |

## 三、游戏属性与成长

| 字段 | 内容 |
| --- | --- |
| 初始等级和能力值 | 生命/攻击/防御/敏捷以及基础生命力/腕力/耐力/速度 |
| 初始个体属性区间 | 每项**最小／最大／分布条件**；须说明具体服端与等级 |
| 四属性 | 地、水、火、风原始数值及生效条件 |
| 成长 | 成长档、升级每级变量、成长公式、等级限制、转生修正 |
| 技能 | 自带技能ID及名称、可学技能、等级/触发条件、效果及源数据 |
| 捕捉/取得 | 是否野外、地图ID/名称/坐标、遇敌等级、道具/任务/运营奖励、首次可证时间 |
| 后续系统 | 进化、融合、骑乘、换色、特殊版本等（不存在或待证要明确区分） |

## 四、每个字段的状态

- `VERIFIED_CLIENT_LOCAL`：原客户端本地编译名称／资源位置已验证，**不证明官服发宠**。
- `VERIFIED_SOURCE_DERIVED`：由完整源字节验证的图形/动作派生数据，不代表原游戏真实播放行为。
- `CROSS_VERSION_CANDIDATE_ONLY`：跨地区/版别同名字、同号或SPR哈希候选，不能写成同服Pet ID。
- `OPEN_NOT_PROVEN`：暂无同部署原证，字段应为 `null` 而非0或猜值。
- `PARTIAL_EVIDENCE_PROFILE`：已经逐项建档、有可验证内容，但没有满足完整验收条件。

### 完整完成的严格门槛

“**完整历史验收**”至少同时要求：身份/来源、原生2D资源、初值与初始区间、成长规律、技能、出现/捕捉/奖品方式和官方实际发行资格均有对应的原版证据，或明确说明某项在该版本**经原证确认不适用**。客户端源数值与另一个年代的社区服务端数据**不允许静默混填**。目前没有任何宠物达到这项门槛。
