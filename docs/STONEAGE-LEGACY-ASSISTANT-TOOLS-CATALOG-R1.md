# 《石器时代》外挂/辅助工具历史谱系与内挂候选｜初次来源清单 R1

2026-10-17。工作包 `LEGACY-ASSISTANT-HISTORY-AND-PET-COVERAGE-01`。**本清单是首次有明确时间与来源的外部工具考古，不是“已经找齐所有外挂”**，不是任何原版服务端已存在某工具的证明，也不是已批准的内挂开发规格。与 `docs/STAGE-B-COLLABORATIVE-DESIGN-BRIEF-R1.md` 配套；研究成果可在之后共同设计中吸收。

## 为什么把外挂研究作为重要的设计输入

外挂历经早期窗口加速/少遇敌、战斗自动化、脚本料理、宠物成长判断、自动捕捉、任务寻路、离线机器人，反映了玩家在重复操作、信息不透明、路线导航和漫长练级上的真实痛点。同时外挂里的封包篡改、复制、越权传送反过来证明**不能把“老玩家常用”直接等同于“应该官方内置”**。把正面体验做成游戏内部原生功能，而不是再次制造外挂依赖。

## B. 内挂吸收建议，不复制旧协议外挂

| 方向 | 推荐程度 | 推荐成品行为 / 必守的设计边界 |
|---|---|---|
| 宠物成长记录/四围预测、来源可追踪图鉴 | **高** | 原始测量、算法预估、推测分别显示；未知初代成长不得假填 |
| 任务/地图路线提示、探险日志 | **高** | 只走可达真实道路，未探索地图按体验机制解锁；禁止穿墙瞬移 |
| 血气阈值自动补给、宠物保护、战术预设 | **候选** | 消耗真实道具/行动；可暂停、可取消，不越过战斗行动预算 |
| 自动整理、批量料理、战斗倍速/跳过演出 | **候选** | 生活成本与时间预算透明，不超速生成资源或额外奖励 |
| 已知地图遇宠地点、捕宠等级过滤 | **需评审** | 只是辅助观察/选择，捕捉和遇敌仍受规则约束 |
| 经验、掉落、成长与任务进度统计 | **高** | 游戏内自然数据记录而非外部封包嗅探 |
| 可编排的离线本地操作/脚本 | **单独批准** | 必须沙盒化且受游戏逻辑限制，默认关闭，不加载不明外部插件 |
| 断线重登、网游多开、后台服端机器人 | **替换/不需要** | 单机应采用可靠本地自动保存与恢复，不追逐多个网络账号 |
| 复制/修改物品和宠物、越权进入、封包欺骗、穿墙 | **不采纳** | 只记录为外挂史；不得冒充合理游戏体验 |

原生内挂的执行位置建议位于 `UI选项/任务规划→受限制的语义动作API→权威确定性游戏规则`，而不是使用屏幕模拟、外挂DLL或客户端与服务器封包漏洞。高级自动化如挂机和脚本是否会削弱探索与人物羁绊，需要双方另行决定；不能在历史研究时直接定案。

## C. 研究采集标准和下一包边界

每个家族至少保留 `product_family, alias, region, era_attested, claimed_release_version, earliest_verified_document, feature_first_attested, proof_level, build_scope, format/syntax, adoption_review, copyright/source_custody`，找不到则填UNKNOWN。优先寻找2001—2004同期开发者主页、发布日志、截图及SHA可靠的早期压缩包目录与当代媒体报道，**不执行来历不明的古老外挂**；再以正式与私服分层，补后期ASSA、STW、NG、小明、石器圣手、SaSH、StoneBoy、SaxTop。每两轮无实质来源或新功能差异即停止横向扩张，回到宠物/玩法资产矩阵。
