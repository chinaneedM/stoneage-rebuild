## 三、矛盾和歧义

1. S1 一针见血 vs S2 针针相对：不静默规范为同一技能 ID。
2. S1 驯服宠物 vs S2 驯伏宠物；S1 招雷术、以形换位 vs S2 召雷术、移形换位：保留字面异文，不自行纠错。
3. S1/S2 可见技能列表数量不一；平面化文本无法解释所有表格跨列条件，名单差异不证明真实系统删改。
4. 一般二级技能职业等级 >=2 与尸体掠夺特殊 >=5 需并行保留，不能把例外删去。
5. 技能点“上限 16/每级 +1”只是页面陈述，不能作为角色成长或存档实测。
6. “7.0”版本标签来自同期门户，未认证完整运营地区、发布日期、服务器 build，更不回填 1999 或 TW1.0。
7. 同名“座骑攻击”涉及宠物乘骑，但仅说明职业技能依赖；既不恢复坐骑判定、首次骑乘体验，也不做新游戏设计。
8. S2 技能名与 S1 示例的文本关系不足以生成完整技能树、属性公式、熟练度提升计数器。
