## 与已有世界线的四项不合并

1. S1未名新岛不自动等于S2的方位参照岛；缺明确名称与对应链接。
2. S1两个未名洞窟不自动与S2封印洞窟合并；不能补出两篇之间的真实任务开放链。
3. S2沉没岛不自动接入2006米莱亚群岛；没有“洞窟→沉没岛”的具体地图边，也没有机械文明遗迹结论。
4. S2一次一只不解决JSS1999–2000宠邮计时合同；数量与时间、不同地区时期各自保留，不认证一条连续补丁谱。

旧7月报告、2006地理报告、JSS宠邮变更、TW1音效门及19集合归档合同都以原字节长度、SHA256与Git blob固定。七条目录记录使用既有集合：versions一条、maps两条、encounters一条未名生态提示、tutorials三条操作文献。全部来源S2、原ID为null，研究权利状态不允许生产使用；不是七个已认证游戏实体。两处区域也不等于完整地图载荷复原。

**HYPOTHESIS：** 隐去通路、分阶段开放可形成探索驱动体验，但这不是已证开发者意图。后续新作采纳、改动或舍弃仍待共同DESIGN。
