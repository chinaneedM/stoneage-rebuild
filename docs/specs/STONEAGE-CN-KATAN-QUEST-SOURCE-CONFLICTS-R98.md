# R98：卡坦的愿望 — 2001／2003 玩家攻略的具名 NPC 与交付环节冲突

**问题与止点**：在寻找早期可验 NPC 原画／游戏绑定的过程中，查到两份不同门户可读的具名卡坦任务记录。先以两个阶段的宠物交付和中间凭证分歧建立可核来源规范；**没有找到并鉴真原版 NPC 的图像像素或原版服务器脚本**，故本报告仅关闭文献关系核对，图像／运行层继续 OPEN。

## 证据

- S1：[17173《卡坦任务祥解》](https://news.17173.com/z/stoneage/content/2001-6-14/n950_866585.html)，作者陶陶，网页显示 2001-06-14；当前迁移页玩家投稿，非华义/JSS 原始脚本、精确客户端或发表时原 HTML 校验。
- S2：[新浪游戏《卡坦的愿望》](https://games.sina.com.cn/zhqu/sta/rwgl1_6.shtml)，显示 2003-05-29 14:24，注明网友投稿；2003 页面有多段画面图注，但本文**未取得文章内相关图像的可验原字节或原图与 build 的绑定**。
- 2021 年新浪自媒体出现与 S2 相近的同文重排，非第三份独立早期游戏执行证据，不重复计数。仓库既存 R81 “梦德洞窟”的卡坦村叙事也不是本次同名 NPC 的任务主表。
