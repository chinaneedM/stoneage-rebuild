# R95｜2003日本《石器时代》复活测试版：交易窗口、地图与角色改动的版本边界

**对象与必要性**：恢复“1999 JSS 日服→2003 BOTHTEC/NHN复活测试计划”之间**有来源归属的UI变更陈述、测试时间变化和地图/人物计划**，不凭同期宣传把交易、原NPC、新地图或宠物骑乘写成已执行的原版规则。前一轮R94已结束Avatar周边归档，本轮返回**玩家交易界面**及地图/角色迭代的同期来源；这也是复原流程里一个必要的版本差分入口，而非新的游戏功能开发。

## 三个不同日期的同时代报道

**S1｜2003-07-26**：4Gamer OGF会场及采访《［OGF＃06］ボーステックが「Stone Age」を復活》，https://www.4gamer.net/news/history/2003.07/20030726001803detail.html 。记者说展会播放了老StoneAge画面，采访中得知将作为升级版本推出，预期有地图和角色追加及少许UI改良。此时公开测试计划为**11月**。文中“韩国当前版＋α”的推测及希望玩家也能骑龙属于记者推测/愿望，**不是受访者确认，更不是日本1999原封包或2003角色骑乘运行证据**。1999版权／运营记述是当年媒体背景，不提供JSS原客户端构建。

**S2｜2003-11-25**：4Gamer《MMORPG「ストーンエイジ」のβテストは12月に！》，https://www.4gamer.net/news/history/2003.11/20031125203537detail.html ，报道运营方将先前11月安排改为**12月**，但**截至11月25日未定日期**。5人组队等介绍是产品概述，不能把它当这次新增游戏机制或源主表恢复。

**S3｜2003-12-12**：4Gamer《「ストーンエイジ」のオープンβテストが12月16日より開始》，https://www.4gamer.net/news/history/2003.12/20031212000000detail.html ，报道BOTHTEC/NHN Japan宣布**12月12日起提前开放客户端下载**，并称**12月16日拟开始公开β**。其重点有一条更具体的UI说法：**增加交易窗口（トレードウインドウ）**并作其他小幅界面调整；报道同时区分“β结束后”拟进行的大更新，其内容是**地图扩张和新增玩家角色**，不是“12月12日已经上线的新地图和新角色”。

以上为2026年当前可检索、带2003页面时间标签的媒体文字。**没有抓取、认证2003原始HTTP字节或当年安装包**，精确客户端build、实施日期、用户是否按下交易窗按钮和成功服务器应答均未知。网页文章的 `00:00` 标签不能断言公告发生在午夜。
