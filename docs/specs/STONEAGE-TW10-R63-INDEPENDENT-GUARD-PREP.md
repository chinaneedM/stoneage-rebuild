# R63 independent derived-artifact structural guard — preparation

This acceptance guard is **prepared but not a historical original-static acceptance**. It validates a future R63 JSON report's pinned runtime identity label, 139-node/156-edge bounded-context claim, two exact WriteFile call/postcall RVAs, decoded instruction row completeness and local-edge closure, and every required **negative** semantic claim. It rejects raw executable/payload fields, duplicated or re-ordered addresses and edges, invented native EAX success, ABI preservation or disk persistence.

All test instruction mnemonics are synthetic. A passing synthetic fixture cannot prove any original instruction. Final acceptance still requires an independently requalified original-source Action HEAD/run, exact artifact ID/SHA256, reproducible metadata and source guard, negative controls, and branch/main CI. Never publish an original program blob.

Stage A restoration-only; Stage B game design remains deferred.
