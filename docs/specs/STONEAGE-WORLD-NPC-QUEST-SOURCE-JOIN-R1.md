## 三条攻略来源怎样并排使用

1. 既有新浪任务汇编当前文字报告“弥生送贝壳给日美子、获得花”及丢弃惩罚。原目录日期不能认证整段字节在2001年1月已存在。
2. 新取得17173玩家诗雨的文章，原发表栏标注 **2001-12-10**，将此任务列作取得不可思议贝壳的方法之一，并给出玛丽娜斯[114,662]、萨姆吉尔[637,491]的位置参考。当前网页的日期声明不是2001网页字节的独立存档认证；作者描述也未锁定具体客户端/服端构建。
3. 新浪 **2003-05-29** 友谊指南描述两个方向及重复任务扣魅力1；这是后期出版规则，不与“丢弃扣魅力2”当作同一操作。

诗雨文章侧重取得贝壳的途径，汇编侧重交付后获得花。二者不应强行二选一，也不能把“获得贝壳”自动解释为最终奖励。当前配置中贝壳与花是两个独立ID，更支持把中间携带物、交换物和奖励角色分别存档；这仍不证明两份文本与保存包为同一服务器构建。

攻略位置参考与NPC出生范围属于**未建立对应的坐标语境**；没有地图ID、区域变换和同版来源就不将[114,662]改为[55,92]，也不据数字不同断言某篇错误。
