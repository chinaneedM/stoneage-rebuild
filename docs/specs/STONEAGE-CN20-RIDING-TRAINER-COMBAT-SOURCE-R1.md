## 骑师与学习流程

来源把“宠物骑师”放在四大村附近的四家族庄园、族长家内。流程为：先向骑师询问人物适合的两只候选→取得其中一只并带在身上→交学费学习符合宠物等级的课程→满足课程与宠物等级关系、宠物忠诚满100→在宠物栏选择“骑乘”。课程分下/中/上三级，但各级宠物等级上限和费用没有提供。

文本同时说“一种雷龙或一种老虎”和查询适骑“两只”，不能推出可以同时学两种、任意雷龙/老虎通用或精确角色—物种表。只说能进入族长家便可付费学习，家族成员/邀请函的实际进入限制仍未知。

关键区别：训练对象是人物，来源明确说换一只原来学习时所用之外的恐龙没关系。不能据此生成宠物技能栏、存档flag或绕过原有适骑/等级/忠诚限制。此2001规则也不能直接替代后续骑宠证书、新手赠骑计划，或回填台湾1.0/JSS1999。
