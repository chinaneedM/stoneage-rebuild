# UI-SEMANTICS-01：台湾1.0五类客户端状态/交互原证对照

2026-10-16。结论：**五类原客户端数据形状与交互消息来源对照已闭合；原版视觉绑定仍 OPEN**。本报告不是原版 UI 截图复刻、初代服务器内容复原、Stage A 终验或新引擎选型。

## 证据判定方法

- **V1_DIRECT**：已验收的台湾 Waei/JSS 1.0 客户端 sa_3.exe 中编译的接收/发送消息字段类型与数量、S 类分支的 RVA、角色/背包/宠物字段位置、战斗 B 的状态路由和零售盘资源索引结构。
- **EARLY_LINEAGE**：旧生成 LSSPROTO 对这些字段的语义命名。结构吻合不能自动把符号名提升为 original binary 中存在的定义。
- **OPEN**：用户实际看到的窗口坐标、按钮、操作条件、资源/声音/动画选择方式，以及来自原始商业服务器的地图、NPC、商品、任务和结算。
- **VERSIONED**：2.5、后期 Windowman 与新玩法扩展，仅可以比较，不得填充 1.0 空缺。

完整机器可读清单：`research/recovered/STONEAGE-TW10-UI-SEMANTICS-R1.json`。包含五类场景、**16 组**原版字段记录、**14 条**编译消息方向/宽度对应、逐字段证据等级，以及 **8 份 Git blob 可复核锚点**。字段名来自原有可校核 schema，而不是由本轮反推游戏截图。

### 资源选择的三个重要禁区

1. 1.0 的 **218 个战斗 SAB 地图**与 **15 个 indexed 调色板**组成233条 battle address-table 条目；另有独立、未被表索引的 `Palet_0.sap`。不允许把它们统称233张战斗地图。
2. 1.0 的 REAL/ADRN 有125996个地址记录，SPR/SPRADRN 有464条地址记录、39065个动画与242085帧。这些是**可用资源的身份/结构**，未直接证明某个 `S:K.graphic_id` 或 `S:I.graphic_id` 一定映射到某帧。
3. 原始音效索引114、松散 SFX 116、BGM 11 属于不同命名空间，不因发生某个 `B` 命令而可擅自指定音效。

### 本轮最小可执行成果

`tools/stoneage_tw10_ui_semantics.py` 对**外部已完全解码的字段序列**提供只读的源规格投影（包含字段号、LINEAGE 字段名、证据身份）。严格拒绝少字段的局部更新、后期多字段、字段类型错误与跨窗口错投影；它不负责原版 token/escape 解码、掩码合并、客户端 UI 绘制或者服务器行为。战斗支路分类仅复刻原版直接观察到的第二字节分流，不执行后代 Z/F/O 扩展。其输出明确置 `historical_layout=null` 和 `visual_resource_selection=null`。

回归用例包括来源哈希、16种源形状、14个消息方向与 arity、原版四种战斗分类+默认分支、原版战斗资源三路区分、合成解码投影及禁止冒充早期已知视觉绑定。所有测试合成输入均非 1.0 服务器实际对话。
