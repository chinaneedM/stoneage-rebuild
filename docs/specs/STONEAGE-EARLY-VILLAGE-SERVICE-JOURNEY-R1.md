# EARLY-VILLAGE-SERVICE-JOURNEY-01｜五类村庄生活动作的有界早期证据合同

**2026-10-17 / Stage A 研究，非新引擎设计、非商业服重跑。**

## 一、这次恢复的到底是什么

目标是为“初入石器世界”的真实玩法建立**可由早期官方文字核对的行为断言**，同时明确台湾1.0原始客户端**只能观察到哪类字段**。这两条来源彼此独立：

- **JSS 第一方手册**（实际存档 2001-04-18，手册页02，§7030、8010、8025、8050、8070、8100）：提供村庄服务/公车/落地物品的早期**规则文字**，并不证明1999首发或台湾1.0商业服的同版实现。其纯派生归档 `research/recovered/STONEAGE-EARLY-CONTENT-GUIDE-MANUAL-R1.json` 的固定Git blob为 `54404a8118f125a9a53eabbb8bad8c4a0d07b190`。
- **已验收的台湾1.0原版客户端**：`research/recovered/STONEAGE-TW10-UI-SEMANTICS-R1.json` 提供位置S:C、NPC窗口WN、状态S:M/S:K、技能S:W、背包S:I和地面实体C等消息的编译结构。字段位置/宽度归属 V1_DIRECT，许多**字段名称含义**来源于 EARLY_LINEAGE。不能把存在“窗口/坐标字段”直接判定为某服务NPC发过包，更不能认定画面已经正确显示。

**阶段成果**：五个有限行为槽、13条可与官方文字逐值核对的陈述、12处原客户端通用字段观测面，以及对未知原商服字段的拒绝规则。没有获取任何原始商服数据、新地图、新动画或游戏运行结果。

## 二、动作→前提→可观察字段→结果限制

| 早期行为 | 官方文字支持的动作/规则 | 原版客户端可能承接的通用数据形状（非事件绑定） | 必须保持未知 |
|---|---|---|---|
| 记录点／回城重登 | 初次使用有供品；下一次进入采用记录点 | S:C 地图与xy、WN泛用窗口 | 供品种类数量、记录点NPC实际交互包、服务端SAAC保存ACK、重登真实追踪 |
| 长毛象公车 | 两个各含3村的线路**分组**；停站3分钟、最多4乘客、行驶中不遇敌；面对车使用组队控件上下车 | S:C位置、S:N队伍字段 | 车费、相邻站点边、真实车厢人数、开关遭遇机制、服务器调度；不是每对村均有直达 |
| 医疗／宠物技能／宠物回购 | 村有相关服务，宠物学技可收费；不是每村有每类设施 | S:M角色HP/MP、S:K宠物状态、S:W技能、WN | 原始村NPC名单、技能项目和价格、是否免费医治/复活/清异常、真实事件结果 |
| 送货与矿石劳动 | 早期手册明确列出送货与矿场矿石工作示例 | S:I物品显示、WN泛用任务窗口 | 任务NPC、货物/矿石ID、领取/交付状态、计价及报酬、完成标记 |
| 普通地面物品过期 | 放置普通物品会在**未知时长**后消失 | 地面C实体、S:I背包更新的通用形状 | 具体秒数、物品持久化与销毁事件；不能与任务物品丢弃即销毁/下线清除混同 |

这五个行为仍应分别归于**JSS2001手册的文字证据**与**TW1.0客户端字段结构**，而非“TW1.0已经复原五条可玩任务”。2001手册可与后期规则对照，但不能倒填后期默认180秒、治疗计费、公交车人数机制等为原始代码事实。

## 三、可重复的真假声明检测（不执行游戏）

归档清单 `research/recovered/STONEAGE-EARLY-VILLAGE-SERVICE-JOURNEY-R1.json` 锁定五个服务的原始手册章节、13个字段路径、12个通用原版可观察槽、缺失前置条件、版本边界和停止点。源码 `tools/stoneage_early_village_service_journey.py` 逐字节校核先前5份已归档来源的Git blob身份，禁止换新版本而不通知。对外提供的 `claim_result` **只是核对有人提出的“JSS2001手册这样写吗”**：

| 输入示例 | 可判结论 | 不可推断 |
|---|---|---|
| 公车停站3分钟、限4人、乘车不遇敌 | 与该手册一致 | 不能推成TW1.0原商服的真实配置 |
| 公车停站180分钟 | 与归档文字不一致 | 不等于已经运行游戏反证 |
| 公车车费0、点到点全直达 | 无手册断言支持 | 不得填入默认0/随意生成地图边 |
| 记录点供品必需 | 与归档文字一致 | 未知供品ID/数量、保存ACK |
| 落地物60秒销毁 | 无证据支持 | 时长保持UNKNOWN |
| 声称任务物品均下线清除 | 无可外推的原版规则 | 与普通落地超时是不同事件 |

检测器输出`MATCHES_ARCHIVED_MANUAL_DESCRIPTION`、`DIFFERS_FROM_ARCHIVED_MANUAL_NOT_EXECUTION_RESULT`、`NO_SOURCE_ASSERTION`、`OUTSIDE_SOURCE_SCOPE`或`UNKNOWN_SOURCE_VALUE`，永不返回“原始服务器已执行”。布尔`False`与数字`0`严格不同。五类中的未知运行参数保留明确字符串和`null`，不得将它们重写为数值默认。
