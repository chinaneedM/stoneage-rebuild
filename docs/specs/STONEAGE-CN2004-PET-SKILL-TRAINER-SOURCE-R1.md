## 五个冲突或不同口径

1. **猛毒攻击**：S1称攻击扣30%、中毒3回合、4400；S2称扣50%、中毒5回合、4000。三个字段不得合并。
2. **一击必杀**：S1叙述平时三倍且『容易被击中』，S2给2.5倍与命中降低30%；S1文字含糊，不得将其补算为S2的命中率。
3. **骑宠课程**：S1说四级、忠诚100、宠物等级最多高人物4级；S2说明下中上三级、忠诚100。S2刊期不明，不证明从三级改四级的更新顺序。
4. **旅途/旅程伙伴**：S1讲带敌人其中一人离场；S2具体讲敌方一只宠物与施技宠物一起离开，尚不能推两个标签是同技能ID或同目标类型。
5. **学习地点**：S1称加工/料理可在萨姆、加加学习；S2对应为SBC，两地名称不同并不代表独占或不可同时存在。
