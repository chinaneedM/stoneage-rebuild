## 如何保留来源并去重

`REFERENCES-R1.tsv.gz`保存43632条引用，每条有样本、逻辑别名、原记录index、物理bitmapno、原ADRN offset/size、偏移/尺寸、attr SHA、可得的完整记录SHA、内容ID及原RD状态。早期表未保有完整80B记录SHA处留空，不造摘要。原record index与目录本地content_id不是游戏实体ID。

`CONTENTS-R1.tsv.gz`保存19236个不同(size,SHA256)原RD块的单份元数据，引用表通过本目录版本内content_id联接。24396次重复内容引用复用这些条目，13579个内容块被多个样本引用；不同源出现位置、物理号、偏移或属性没有因内容相同而删除。43,632次引用指向256992868B逻辑块预算，不同块143169643B，重复引用113823225B；它不是实际原盘回收量。本包没有删除原文件、重拉原大包或保存版权图像；实际原磁盘删除0B。

相同RD原字节不证明在不同色盘下画面相同，不能当像素等价或同物种。同一别名也可能在不同版本或同包不同出现位置指向不同内容：跨样本共有13527键中，13356键的全部现存引用恰为同一个内容块，171键有不同或多个内容候选；171不是已证171项游戏改版，含原重复/覆盖候选，需另作具体材料审查。
