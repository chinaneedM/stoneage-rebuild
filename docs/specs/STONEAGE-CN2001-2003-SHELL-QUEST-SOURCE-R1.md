## 2001玩家稿与2003指南的正面矛盾

S2001 的北岛第一条说：从玛丽娜丝**弥生向萨姆吉尔日美子送贝壳**，就能得到**不可思议的贝壳**；然而 S2003_Q 对**同一方向**写的是奖励**仙尼亚的花**。不能将这一差异静默校正为笔误，也不能据此推断2001→2003某更新必然改变规则；版本、玩家误记、路线细节省略均有可能但尚无原运行证据。仓库JSON保留两条相互矛盾的**来源主张**。

S2001 还另外列出四种取得路线（共**作者列举的五项**，非已证穷尽全集）：南岛哥亚山与卡鲁它村商人、吉鲁岛小猪爱情、吉鲁岛美鲁娜洞窟购入“1000 Stone”、英雄岛饥饿村民食材交换。南岛文中提到商人给予两个贝壳、交回一个可换宠物；不是原服确定的道具掉落/商店库存/宠物选择表。第五条坐标与宠名出现不可解字符，留为未解析；特别不把损坏文本补成明确NPC或宠物ID。

## 贝壳跨任务依赖：50年前的波拉岛

S2003_H 说背包带贝壳，在萨姆吉尔村找**黑乌力（东71，南49）**，可传送到**五十年前的波拉岛／英雄岛**。该后续“英雄岛前传”本身列人物等级要求80、建议120；**不可反推传送入口本身必需80级**，也不证明贝壳被消费、跨次进度如何保存、真正时间旅行的服务器实现或所有游戏版本通用的历史设定。
