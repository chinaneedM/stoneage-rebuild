The post-store comparison permits a **conditional1025-unit chunk**:1023

For complete transfer of all modeled output, total output units minus total
insertions equals consumed input units. Applying that identity to native return

frame/memory and no relevant alias/clobber, the native count pointer/ABI to be
correct, every transferred count to equal the requested chunk, the retained
accumulator route to sum exactly those counts, and all subtracted insertions to
match the output counted. These premises are not proven by the model.
