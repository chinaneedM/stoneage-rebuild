## 3. Reproducible safe intake path

`tools/stoneage_late_client_archive_probe.py --check` validates the exact lead classifications and the non-promotion boundary. For a candidate actually acquired **outside** this repository, `python -m tools.stoneage_late_client_archive_probe --inspect /path/to/archive` computes a streaming SHA256, file size, shallow RAR/7z/ZIP/PE signatures, and a bounded ZIP member-name safety inventory (never extracts or executes). An unsigned magic signature or extension cannot authenticate a publisher, release date, region, 8.0 version or runtime PET feature. If an archive contains potentially unsafe ZIP member paths, the tool marks them; it never extracts those members. Keep original bytes out of this GitHub repository by default.

An eligible clean Taiwan 8.0 client **requires** independent operator/carrier provenance, full SHA256 and file tree, PE original version/build metadata and a no-private-patch chain of custody. Historical PET opcode127 with compatible authenticated client+server must be validated separately. The current candidate set satisfies none of these requirements. A later Taiwan 8.5 version, even if clean, can be an evolution-diff bridge but cannot serve as actual 2005 Taiwan 8.0 execution proof.
