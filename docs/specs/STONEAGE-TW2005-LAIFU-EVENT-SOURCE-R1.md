# R19｜2005 华义五周年犬人「萊福」任务与后期犬人攻略的证据边界

## 研究目的与原始缺口

本轮需恢复一条可真实追溯的宠物获取任务与相关故事，而不是给台湾1.0原服务器补造 NPC、宠物ID或战斗公式。按主线 `a72034baaa02db88969fc8628a4106c41daf4000` / tree `8e51c5559b58c762698238354a22ea5ac9cdf197` 的 CURRENT 与 R2 计划，首次选择**同期期刊媒体对华义活动的具体报道**，而非再取2003玩家投稿。正式一方原网页、当年实际任务脚本以及可重演客户端仍是OPEN。

## 同期资料：2005-04-20 GNN 五周年稿

[巴哈姆特GNN《石器時代》5 週年慶活動開跑](https://gnn.gamer.com.tw/detail.php?sn=19615)，记者小贤，网页显示 **2005-04-20 19:26:02**。页面的石器段落描述：
- 五周年庆活动中，犬人「萊福」为新任务奖品，活动期限为报道时起到 **6月15日**；
- 玩家需带**任务委托书**前往**霍爾特村附近的PC盗贼团基地**营救儿童「乎契」的**父亲**；
- 完成任务获一只**大型人型犬兽**，名「萊福」；
- 宠物声称有技能「相棲共生」，会在主人可能死亡时牺牲自己保护主人。

这份**同期运营商归因媒体报道**比多年后的玩家攻略更适合确立“当时曾公开宣传一个具名犬人任务”。但GNN站点**不是华义原始公告页**。本轮浏览器直开 GNN 返回403，取自网页搜索索引可见的相关文章段落，未获得原HTML SHA-256；不能将搜索节选称作字节级原件或真实服务器任务运行证书。活动中的商品「蟲蟲危機包」属于另一个营销信息，不能归为同一个领取途径。

## 后期资料：2006编辑的犬人领取攻略

[巴哈姆特社区《犬人拿法...任務詳解》](https://forum.gamer.com.tw/G2.php?bsn=1571&lorder=23&parent=3229&sn=2337) 显示作者「戀云少年 c90045」、**2006-10-04 18:22:48 编辑时间**。搜索正文显示约八步的玩家攻略，包括：塔姆塔姆村的乎契、PC团洞窟、渔村附近的叔叔「拓那哩」、乎卓、送信、交骨以及霍村外的「多格樂」。后期攻略提供较详细的“委托书→找父→信件→犬人”流程，可为未来任务设计提供候选线索。但编辑日期并不意味着首次发帖日期、改版部署日期，也不能证明2005报道的一次性活动在2006始终开放。

本轮明确不自动合并：
- **萊福**（2005稿中犬人奖励的名称）与**多格樂**（2006指南中交付犬人的名字）。
- **乎契的父亲**（2005稿未具名）与**乎卓**（2006指南具名）。
- 2005一份**任务委托书**与后来攻略里描述的**GM委托书、乎契委托书**。
- 霍爾特村旁基地的故事定位与后来地图`603,128`、各楼层和NPC出现点。
- 2005技能一句宣传与任何原服血量临界值、持续时间、战斗消耗、宠物等级或触发脚本。
