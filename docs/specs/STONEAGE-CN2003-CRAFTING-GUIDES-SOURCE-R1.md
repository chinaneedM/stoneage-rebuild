## 跨来源冲突：不得合并为确定性配方

S1 新手示范使用“木1”“石1”并报告一件“枪”；S2 的 **石＋木** 行归在“枪”(40–60%)，而 **木＋石** 行归在“投掷斧”(30–60%)。若无序地比较材料集合，它们重叠；但**原游戏是否检测材料顺序**、配方结果是否随机或因等级/宠物不同，完全不能由这两份网页确定。尤其不能从“存在同一无序材料集合”推断“单次操作能产出两件不同装备”。S1 的加工流程亦混用“加工/合成”措辞，未取得原UI画面或实际技能ID，暂不规范化成唯一控件/执行状态。
