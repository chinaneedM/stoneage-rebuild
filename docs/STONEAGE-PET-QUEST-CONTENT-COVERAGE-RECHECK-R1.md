## 一、准确回答“是不是全部宠物和任务都恢复了”

**答案：没有。** 要达到能够为新游戏选择/重做“所有宠物”提供基础的水准，不能只验收资源格式和一部分成长函数，必须在同一版本内把**模板/名称 ↔ 图片 ↔ 动画/动作 ↔ 属性 ↔ 成长 ↔ 技能 ↔ 出没/捕捉 ↔ 宠物/骑宠资格**关联成可校核索引；当前这一整套跨表不存在。

**台湾1.0直接实证**：
- 完整可追溯原始客户端资源容器规模：ADRN **125,996个图像记录**、SPR **464组**、约**39,065段动画、242,085帧**，不是125,996只宠物；不能反推出宠物种数。参见 `docs/specs/STONEAGE-TW10-UI-RESOURCE-BIND-R1.md`及其固定JSON验收。
- 原版 S:K 中有21字段宠物传输形状、候选图形身份位置；**没有经验证从每个graphic_id到原版SPR组/动作帧/2D画像的完整连接**。图像与帧可核验、能作为提取候选；不等于宠物图鉴能准确显示。StoneAge的经典图形资产本来是**2D精灵与帧序列**，不能按3D模型实体数计算。
- 普通野外地图/NPC/任务为早年商业服发来的内容，而零售盘没有完整普通场景地图；客户端资源不是世界和任务主数据库。

**后代同源控制**：
- `research/recovered/STONEAGE-TW10-VS-25-RESOURCE-DIFF-R1.txt`显示台湾1.0的125,996原图像记录与464个组在指定2.5来源前缀中均有同字节继承关系；**不代表它们都是宠物、更不证明每个宠物应出现于1999商业服**。
- `research/recovered/STONEAGE-25-PET-GROWTH-R1.txt`计数**后代active enemybase 988行、另一inactive版本640行**，其rank构造可追；这是**后代敌人/宠物模板记录数，不是初代确认宠物种类数**，不得整表回填初代。
- `research/mechanics/STONEAGE-PET-GROWTH-CORE-R1.md`恢复的是多后代保留的成长算法/宠物rank，且明确未证明1999原服同系数；`docs/STAGE-A-CONSOLIDATED-REVIEW-R1.md`继续列出初代当前MP、经验阈值、完整技能/状态和宠物自动初始化等缺口。
- 捕获→入栏→本地读档→再战→受控成长在**明确外部测试状态下**成立，不是初代所有宠物可独立出生成长或原服验证。

**任务、NPC、场景与交互**：
- 初代NPC、对白、脚本、任务分支、条件、物品奖励及持久化属于**OPEN**；有晚期任务指南/后代保存包的绑定与参考规格，但同源原始完整任务清单不存在。
- 台湾1.0有通讯UI字段和场景/调色板结构，然而实际原版运行的贴图/动作/声音/按钮选择仍未重建完整链。
- 多版本都应独立建立“该版本能有多少宠物/任务”的分母；不能以原版JSS1999、TW1.0、国内1.82、2.5及后期全部膨胀内容混成一张未知年份大全。

## 二、需要建立的可执行完整性矩阵（下一步为具体工作，不是当前已完成）

| 维度 | 首要交付 | 有材料时认定闭合的条件 |
|---|---|---|
| PET-TEMPLATE | 逐版本物种/变体/模板/名称ID名录；每项证据链接 | 每行有来源、格式解析、同版归属、唯一性处理 |
| PET-IMAGE | 逐版本2D头像/立绘/位图记录与图形身份连接 | 同版字段→可用贴图文件/图像ID可追，缺口列UNKNOWN |
| PET-ANIMATION | 每宠各动作与朝向的帧集合/调色板 | 对实际UI、战斗/地图场景的选择可复现，允许已知缺失 |
| PET-STATS | 逐宠基础属性与元素/其他状态 | 同版原表或实时证据，不拿后代默认初代 |
| PET-GROWTH | 每宠成长配置、个体差异和升级规则 | 源公式/配置/实例实验一致，未知首代系数保留候选 |
| PET-SKILL | 技能可学/自带/来源/费用/等级限制 | 同版校核，不把后期技能灌入早期 |
| PET-HABITAT | 野外地理、野生等级、刷新与可捕性 | 逐版地图和遇敌表/NPC证据闭环 |
| PET-RIDE | 骑乘资格及地图/战斗动作绑定 | 区分后来正式版本与最初年代，无首发假证 |
| QUEST | 任务ID、NPC对白、触发/阶段/奖励/保存 | 原始商服材料或确证同期可归属链，而非后代猜测 |
| WORLD-NPC | 同版地理、NPC、画面与交互 | 可验证世界载荷和NPC显现/条件路径；不报无分母百分比 |

建议矩阵每行字段：`version_profile, source_type, source_sha, pet_id, template_id, graphic_id, sprite_group, action, name, base_stats, growth_config, skills, encounter_map, quest_links, verification, unknown_reason`。宠物的**原始图像只能在合法具备来源的研究环境分析**；不把第三方客户端商业资源默认作为新游戏发行素材。
