## 一、2019 台湾春节：2019-01-29 原运营口吻公告的同期玩家转贴（本批新增核心来源）

[2019-01-29 巴哈论坛楼主转录](https://forum.gamer.com.tw/C.php?bsn=1571&snA=81196)：帖子发于 **2019-01-29 19:04:31**，自标公告发布时间 **2019-01-29 15:45**，活动声明 **2019-01-30—02-20**。内容称「黑烏力王降臨薩姆吉爾村」；本次礼物随机一种 **「豬能力提昇血清」**（物品，不是宠物）或 **「豬年寵物袋」**，宠物袋文字有机会给 **「烏力王、黑烏力王、豬年」**。又宣告：烏力／布伊系列强化后专属技能「變身」，豬年强化专属技能「衝鋒」，烏力王／黑烏力王强化专属「烏力化改／黑烏力化改」。**仅限运营口吻的同期玩家转录**；未核对原 `stoneage.tw` 公告 HTML / 官服同构建技能函数 / 发宠数据。不能由此将所有猪、蛋、年兽、强化变身形态数成2019新增物种。贝壳少女交换道具罗列仅是**兑换材料/物品**，不是当年实发新宠群。

同一帖楼主在 2019-02-15 更新的操作攻略称从黑烏力王开始、认养四种「初心者」乌力、练至 140 后交任务，并列自称已知随机奖项（含四属性豬年）；2019-01-31 其他玩家声称交付140级领取 **風豬年**、另取得 **黑烏力王**，还有自述「黑烏利化」技能；3月玩家试验表列多个乌力/布伊变身目标。此层为 **2019 现场玩家获宠与技能文字见证**，较纯计划稿多了实操证词，但不是本助手当期原生客户端运行，也缺账号奖宠日志；同一原帖多楼层不应误算为独立官方公告。该帖网页直接读取403，搜索索引返回当年帖子内容，存在索引与日后编辑层风险。

**首发时间负证：** 早年已存在 [乌力王任务](https://forum.gamer.com.tw/G2.php?bsn=1571&sn=15) 玩家攻略，因此 2019 年春节再度可获或可强化 `烏力王` 不能被当成该宠物的全球历史首发。2019「豬年」准确四属性、变体是否独立物种、技能是否永久、是否逐服同发皆未由原始文件裁定。
