## 2015资料的权威等级与年度实质边界

1. **大陆胜思**：PET100的2015春节“精灵觉醒2.5/8.5”不同奖宠／骑证文案来自第三方网站的所谓官方原文**重刊**，非自行读到2015胜思原运营HTML、原程序。该文案把第二、三期开始日期写在2月，截止写成1月，**原文日期自相矛盾**，既不能据此校正成2月18/25，也不能宣称已真实发蛋。不同服的蛋、外观、骑证、玩家练宠排行需求不构成一张统一的同版宠物原生表。追查2015年付款行为或付费盘不在本项目范围。
2. **台湾陶朱原PC**：PET101记玩家下载标签**199（2015/2/25，后期编辑）**、2015/3/6同期玩家操作自述`launch.exe→Newlaunch.exe`更新至**200**、2015/9/22同期玩家转录官方维护公告所称**202**；均是数字标签，不是认证客户端、原补丁或202种宠。PET100、102明确**2015/6/17端午「五月节的插曲」与摩洛索思（麒麟）只在2016后编辑的玩家编年出现**，而2015/9/24同期玩家第一人称只证实拿到**「三頭蛇禮盒」道具**，不是开出蛇活宠/新品；2015万圣节PET104在同期公告重刊列8类奖项、5个具名候选与3类道具，玩家又报告“南瓜礼盒→骨龙蛋”，原重刊公告8项**没有「骨龙蛋」字面**，不可猜测它对应史凯勒顿/古斯特或确认实体。PET103同期圣诞讨论报告**鲁道夫、胖达利、库胖达、布伊酷、冠军猪**不同奖励和礼包/麋鹿缰绳/奖杯/衣装类别，圣诞跨入2016并不形成二次首发。2015/9/22官方`news.php?id=1452,1453`和圣诞`id=1486`均只在同期玩家转录中可定位，原官方页不可直接验证；端午原官方网页URL仍未定位。**没有用后期2017/2023/2016节令任务奖池回填2015。**
3. **香港/澳门**：PET101已直接核读DigiPark**2011/9/8原厂新闻稿的当期逐字转刊**，授权陶朱同一运营商香港及澳门正式运营权，属对**历史授权**的第一方文本，但**不能证明2015港澳仍独立设服、已合入台湾哪个分流、共用台服202同一PET原生资源或有特别奖宠**。两法域一条地区审查，保留与TW分开。
4. **韩国Netmarble原PC**：PET100取得2015同期游戏媒体称原PC《StoneAge》**拟于2015/8/21结束服务**，对关服事实层次属于媒体报道/运营人员表述；未取得原PC营运终止一手公告、日志或最终2015客户端主表。另取得Netmarble**2015/5/22官方原文**，明确是另一款`StoneAge Mobile`拟2015/8/21结束，其官方手游公告**不能当韩国原PC的一手结案证明**。2016年移动新作/宠物不得混进2015原PC。
