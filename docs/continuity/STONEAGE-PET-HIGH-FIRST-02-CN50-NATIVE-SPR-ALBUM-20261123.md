# PET-HIGH-FIRST-02｜大陆保存 5.0 的相簿名与原 SPR 动作索引

经典 PC 宠物模块。本轮从同一份 [Stoneage-5 保存载体](https://archive.org/details/Stoneage-5) 选读原程序及资源，复算客户端按 SPR 图号登记相簿名的规则，补齐先前旧公式未命中的 115 个具名槽位。原程序有两处采用相同的分段换算，其中持有宠物路径多九个图号排除条件。

原程序从 SPR 图号先减 100250，再依区间继续减偏移。增量 `0x39f` 单独指定槽位 293。两个相关分支最终都按 28 字节相簿记录寻址，并跳过首字段为 `-1` 的空槽。持有宠物预览在另一处把同一宠物图号传入 SPR 序列查找，按图号、方向和动作编号选序列。在相簿登记时持有宠物分支有独立开关。场景动作对象分支有 79 个 SPR 组换算到 49 个空槽，另外 512 个组的号码换算后落在相簿范围外。图号排除也按原路径分别保留，例如 `101279` 在场景动作对象路径进入葛雷马恩槽位，在持有宠物登记路径被排除。

## 头像别名的原程序选择

保存包的原加载循环每读一条 80 字节 ADRN 记录，把物理位图号写入该逻辑别名的表项。305 个相簿别名均走无额外位图号限制的分支，后出现的同别名记录覆盖前条。原相簿传入的别名经该表查到物理位图号，并存入绘制队列。全表回读只有洛克斯、阿伊萨、格洛格鲁、朵洛将恩四项各有两条，按文件顺序加载后的位图为 126222—126225，早先的 126066—126069 仍在原资源中。这个结论限定在读入该份原 ADRN 的静态加载与相簿代码路径，实机观察仍待做。

## 复核与接续

以远端 `main` 的 `26e52ac9f0462ccc1c69a2efc9ed6f163787ba25` 和 tree `254ef165b86e2ebdc76923c20526df3401d1afe4` 为起点，检查 9,200 个文件、1,268 个远端分支、0 个开放 PR 和该提交的 16 个成功 Actions。完整 [CURRENT-STATE](../CURRENT-STATE.md) 为 2,709,173 字节，Git blob `c89e0e33537990aa2132b47c40fef49a985a935c`。本页作为当前工作增补。

使用光盘的 HTTP 206 字节范围取回 CAB 开头及第 1、2 号压缩文件夹，重新解出 `sa_5000.exe`、`adrn_31.bin`、`spradrn_17.bin`、`spr_17.bin`，四者整文件 SHA-256 与先前 CAB 验收逐一一致。反汇编解释器独立复算 4,000 个图号及两个分支，与分段规则完全一致。全量重导 1,185 个 SPR 组、96,783 条动作表头、598,455 条帧记录，三份派生表均与已存版本逐字节相同。本轮头像使用完整原 ADRN 与既存 RD 摘要，没有重新下载完整 REAL。来源指纹和原指令区间见[机读档案](../../research/pets/PET-HIGH-FIRST-CN50-NATIVE-SPR-ALBUM-R1.json)，可用[复核程序](../../tools/stoneage_pet_high_first_cn50_native.py)传入同源四个文件再次复算。

按名称或原 SPR 组号查询，详见[宠物档案入口](../pets/INDEX.md)。下一个工作项从已有可靠的高版本 PC 材料核对年兽、蒙奇、艾迪希洛等图号在实际原游戏、同部署宠物主档或运营资料中的身份和用途，并在有原证时回填属性、技能、取得及官服投放年份。早期相簿关联仍按版本保留，PET 模块继续开展。
