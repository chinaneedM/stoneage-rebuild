## 为什么宠物模块现在不能宣告完成

要按协议第19节给出SOURCE_BOUNDED_CLOSED，必须确保全部**当前有资格、可真正取得的宠物源批次**处理或登记了经示范的受阻条件，并输出逐属性覆盖、未解原件与最终来源限定验收。现有缺口包括：

- **物种核心证据：** 没有同部署早期官方宠物名称/数值/图像主档，故台湾1.0真原2D组不能无证赋后代名字。
- **可见内容源：** CN5/TW85多组原源可追索但像素未重读；不能把源RD索引和整SHA说成已重新渲染。
- **官方网页原图：** 日本已记录124个网页具名位置但原图仅1张独立取得；中国华义104位置有98个具名/6个UNKNOWN，原图来源资格与当前能否取得仍需逐批检查。官方网页图片与同版本客户端SPR身份也不可自动相等。
- **技能/成长/玩法：** 缺源技能不能补造；后代执行验证不能代替初版原始规则，历史捕捉/赠送/进化/骑乘真实行为仍有限。
- **版权：** 研究所持商用原图没有自动进入新游戏/公开攻略网站的授权。

机器矩阵全部7维使用 `VERIFIED_SOURCE / CROSS_CARRIER_CANDIDATE / MISSING_SOURCE / UNVERIFIED_RUNTIME` 证据分级、现有原件指纹、不可推断事项及**精确重开条件**。结项状态明确 `SOURCE_BOUNDED_PARTIAL`、`source_bounded_closed=false`、`historically_complete=false`、`allowed_to_unlock_next_module=false`，不给虚假完成率。
