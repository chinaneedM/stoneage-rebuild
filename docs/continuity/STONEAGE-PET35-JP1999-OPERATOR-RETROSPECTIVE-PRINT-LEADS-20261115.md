# PET35｜1999年日本JSS宠物：继任运营商追述与原期刊缺件（2026-11-15）

**PET仍是唯一活动模块；研究游标仍为1999 OPEN。** 在PET34对1999-09《Play Online》No.015的原PDF做精确来源保管之后，本次找到一个不同类别的继任运营商声明以及五期尚未审核的1999期刊目录；以下两者均**不**构成1999年具名宠物实装。

## 2005年正式运营商声明：有官方继承性，但不是1999原始运行记录

2005-04-04 14:00，日本 **株式会社GaiaX（ガイアックス）** 在其发布的运营权新闻稿中写明：日本系统供应JSS于1999年开发/运营《ストーンエイジ》；2000年JSS破产，DigiPark继受权利，2003年Bothtec恢复日本运营，2005年GaiaX取得日本国内经营权。新闻稿又对该**游戏/系列**作总体介绍：玩家在冒险中遇到恐龙、令其成为宠物并一起冒险，亦可使用宠物Duel。

原始可查看的发布页：https://www.value-press.com/pressrelease/931 。这是**继任运营商2005年第一方历史追述 + 当时整体玩法介绍**，不是 JSS 1999 同版的具体宠物发行说明。**不能**把新闻稿相邻的“1999年”和“收服恐龙”拼成1999年某具名物种已经实装，不能把2005年叙述的Duel规则当作1999原版实机证明。

交叉参考2004-05-20 [4Gamer对Bothtec重开的报道](https://www.4gamer.net/games/013/G001377/20040520194557/)：所述2003年12月β测试及2004年6月3日预定正式运营，是**后续日本运营时期**，不能替代初代JSS的原版本。此次2005网页来源是公开页面阅读，**没有独立下载其HTTP原始字节，因此SHA256、原HTML字节数均为NULL**；必须明确区分来源定位与原文件验真。

在 [Retromags《Play Online》保存目录](https://www.retromags.com/files/category/230-play-online/) 确认存在列名：**No.013（1999-06）、No.014（1999-08）、No.016（1999-10）、No.017（1999-11）、No.018（1999-12）**。这个列表仅为书目/数字保存入口：本轮**没有读取这些原期扫描或其中的游戏页面**，无法证明它们收录《STONEAGE》，更不能证明含具体宠物名字、官方投放或参数。No.016的[档案目录页](https://www.retromags.com/files/file/7019-play-online-no016-october-1999/)标示“310MB”，仅是站点所列元数据，非本次实取文件体积/哈希。以前已研究的No.012与PET34的No.015不重复计新发现。仅在取得原期可读文件及有关系页时才进一步判读；不用用户购书，原杂志扫描不可无权上传公开Git。
