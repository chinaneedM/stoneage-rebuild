## 允许继续整理的执行办法

1. 年份和地区版别轴不变：当前2000年官方发行清单仍 OPEN，不因为查到晚版资源而跳年。
2. 旧版原盘无可靠可得途径时保留缺件和重开条件，并直接转用已保管的后版客户端，先按该后版的真实或候选来源身份，批量整理本地名称、图号、原2D、动作、技能等。
3. 与早期有据原盘按不同强度连接：同数字、同原始名称、整段SPR相同、同构建名称和图号、原服实际发布分别记证，不能混成一个标签。
4. 高版反向补录仅补“早期参考候选资源”；不得倒填后来才出现的宠种或私服独占宠，不能由资源存在推出早期等级成长、捕捉、活动发放或正式上线日期。
5. 新原客户端一旦出现，按哈希、版别及本地表更新源限定字段即可，不必推倒目前目录重做。
