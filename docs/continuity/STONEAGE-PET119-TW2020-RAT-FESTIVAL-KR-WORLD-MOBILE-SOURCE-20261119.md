## 1. 台湾原版 2D PC：2020 鼠年任务的同期运营口吻转录、玩家实操与更新异文

[2020-01-20 当期巴哈玩家帖](https://forum.gamer.com.tw/C.php?bsn=1571&snA=81308)显示作者编辑日期，并引述称 **2020-01-19 20:17** 台湾石器时代客服中心所发鼠年活动公告。网页直接获取受限；可读搜索索引属于 **`CONTEMPORANEOUS_PLAYER_OPERATOR_VOICE_RELAY`**，不是经过核对的当期陶朱官方网站 HTML，也不能证明所有发奖已经在服务器实际部署。

该转贴称：

- **万年找五鼠：** 完成鼠年任务随机奖励「**鼠年**」、风地猫「**卡芙娜**」、水火猫「**卡蘿麗**」。活动长度称**一年**，但两种猫另明写 **2020-02-19 后无法获得**，因此不得把一年期视作全年都能领取三类同样奖项。
- **四村鼠年兽：** 再生时间声称击败后24小时；不可以把四村挑战中的「鼠年兽」四种外形直接认作 2020 年首次推出的新物种。年兽「**米尼樂、米樂多、米多亞、米多多**」后在玩家转引的 1/28 公告提供四村坐标，是**独立的四个当期敌方/角色标签**，不等于四种新获宠主档。
- **奖励/道具独立：** 鼠年宝箱、鼠年强化血清、鼠年项圈、项圈上的精灵属性、挑战券和兑换券分别是**物品/奖励机制**，不算新的宠物种类。1/19转文还提到场地「英雄战场101楼」可以买挑战券/强化血清；这仅是运营口吻转述，未得到真实商店表。
- **同期玩家作业：** 1/26玩家攻略更新描述等级120前置、迷宫寻五鼠、击败猫女、收集各勾玉找五鼠并回万年换奖励，作者声称实际领奖得到水/风猫或四鼠盒子之一。个人操作见证比计划公告多一步，仍无原同部署服务器奖宠日志、真正物品/宠物 ID 或可复算概率。
- **后续官方口吻异文：** 同帖1/29转述自称1/28四村位置（米尼乐/米乐多/米多亚/米多多）；2/4编辑转载自称 **2020-02-03 15:55** 的春节任务修正公告，**鼠年兽挑战券从战后回收改为不回收**，战后掉落改成「一号/二号兑换券」分别换宝箱/项圈，另将券价降低一半，并增加渔村外养猪人处理猪类强化。**这是真正的版本/规则修正线索，不能拿1/19文字替代2/3之后的原生机制**；该论坛帖内部不是独立多家官源，且原客户端/服务器数据未得。

**2020首次发行排除：** [2011年更早的鼠年兽/宠物玩家材料](https://forum.gamer.com.tw/Co.php?bPage=0&bsn=1571&sn=227002&subbsn=7)已经提及米多亚／米乐多/鼠年系。2020活动再次可领取不等于 2020首次出现此历史物种，亦不能把不同颜色、强化形态、骑宠项圈、敌人和领取活宠混数。同期楼层玩家质疑两种猫此前就在转转乐有过，这只是需要进一步核对的**来源冲突线索**；不把玩家问句升格为历史首次发行否定证明。

**原件缺口：** 尚无可认证的台湾陶朱 **2020 年原经典 PC** 安装包/补丁原字节，未核同版、同星系的 PET ID↔名称↔2D SPR动作/属性/成长/技能、任务和实发概率。玩家网页位置和搜索摘录不是客户端；不能从 2021 发表的回帖倒推 2020 实际派奖。
