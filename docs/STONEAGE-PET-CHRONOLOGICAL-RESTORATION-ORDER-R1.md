# 《石器时代》全球官方宠物：由远及近、按年份／地区／版本逐层复原（PET27）

**生效：2026-11-15，当前唯一活动模块 PET。** 用户提出按最早年份、最早版本到近期逐层整理，而不是哪只宠物有资料就先跳过去；本工作令为连续性协议§21的操作入口，并覆盖之前PET25/PET26的跳跃式调查NEXT。

## 先固定顺序，不依赖用户回忆宠物

1. **最早历史起点**：1999年先作*待证搜索窗口*，认真核查原始日韩运营/JSS、台湾初版的历史来源。1999 **不是**未经核实的“日本、韩国或台湾正式上线事实”。已从次级编年史查到的更稳定早期线索包括**台湾2000年4月20日1.0**、**大陆2000年12月测试／2001年1月1.0**；先取得原始运营方证据再把它们从版别日期候选升为确定历史证据。
2. **主时间轴**：每次选择尚未经过正式范围核验的最早年份：先早期（1999待证、2000），再2001、2002、2003……按顺序至2026和未来新官服公告。不得仅因为2009/2026有易取得的公告就跨越尚待调查的2000/2001。
3. **同年平行版本轴**：按 **TW、CN、JP、KR、OTHER** 五条地区轨道，再按**产品线/运营商/具体版本**建条目；不能假定同一年各地均运行“同一个3.0”，也不能将韩国2020手游的宠塞进日本2004 PC客户端。
4. **同一年逐维清单**：先核地区及实际版别、来源时间，再逐条核野生普通宠、任务宠、生肖活动宠、商业付费宠、融合／进化／繁殖的结果。对每只逐项关联官方原名/别名、宠物身份/形态、原始二维图鉴/SPR动作、属性成长技能、获取规则及同部署的原生证明。只恢复有原证的字段，未知明确写空。
5. **不遗漏的停止门槛**：一个年份只在该年度所有当前可获得的正式版别／官网／运营活动来源清查后，记为 `SOURCE_BOUNDED_REVIEWED` 并留下缺件、未确证和重开条件，才移向下一年。这个状态**不是** `HISTORICALLY_COMPLETE`，更不能假定“没找到的宠不存在”。
6. **新发现自动归年**：以后发现2001年的宠，即使是在2026年才找回旧报纸，也补入**2001年、对应地区和对应版本**，用新收据前向增补，不覆盖过去提交。已经完成的2006/2008/2009/2020/2026事件资料保持原证据，不丢掉、不用后世发行时间取代旧版真实年。
7. **后续新游戏独立**：等历史宠物资料完成来源有界综述，未来独立 `DESIGN_FUTURE` 原创宠物库不写入“历史官方”计数，也不将私服改造物种混进正式发行列表。

## 版本锚点只是历史调查目录，不能作成品宠物身份证据

- [17173 2008年的台服版本历史整理](https://game.17173.com/content/2008-07-04/20080704153827714.shtml)给出台服1.0、2.0、2.5、3.0、4.0等日期，属于晚些年的版本史回顾，必须核原运营补丁；不能用它代替逐宠正式发放证明。
- [新浪所载华义企业大事记](https://games.sina.com.cn/guancha/waei/huayi2.shtml)称大陆2001年1月发行1.0、11月发行2.0、2002年1月底发行2.5；[17173的另一版本整理](https://game.17173.com/content/2008-07-04/20080704153827714.shtml)给大陆2.5写2002年2月5日，具体月日有待源层级厘清。**地区差别**与**来源冲突**都保留。
- [17173 2012年的历史回顾](https://news.17173.com/content/2012-02-21/20120221105152639_all.shtml)记大陆2000年12月15日测试、2001年1月10日1.0；不能把这套大陆时间线套成台湾开服日。
- [日本旧服营运时间轴](https://netgamebm.com/games/view/46)记重开后2003年12月16日公测、2004年6月3日正式运营；这是**后期开服时间，不是已证日本最早JSS原始首发**，日韩1999以前/后早期正式版仍需独立来源。
- [2002年11月台湾融合报道](https://gnn.gamer.com.tw/detail.php?sn=6751)仅证5.0阶段的融合机制，不等于当年所有三代融合宠都已经有独立名字/ID的可证收据。
