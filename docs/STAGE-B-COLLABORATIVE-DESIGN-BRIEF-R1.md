# 新《石器时代》｜Stage B 共同设计讨论预备包 R1

**性质：设计议程与方案草案（DESIGN）**，不是原版事实、不是已批准的生产需求。前提是Stage A证据受限研究检查点已经接受；未经共同讨论，仍不选择最终引擎、不生成正式游戏内容、不开始生产性改造。

## 一、先说我们要做怎样的游戏

一款**本地单机、2D、回合制、重视人与宠物羁绊的石器文明冒险RPG**。不模拟网游账户、服务器商业运营或强制社交；把早期世界的村落生活、漫游、遇敌、宠物获得、慢慢成长与“第一次骑上宠物”作为体验主线。后来版本里有价值的元素只能在设定逻辑与节奏合理时另行选用，绝不直接堆叠成杂货铺。

### 拟保留的五个体验支柱（均为**新作设计方向**）

1. **生存感与好奇心**：小规模出生/初始村落、道路与原野、有目的却不全被任务指示追逐的探索。
2. **人物和宠物双核心**：伙伴不仅是战斗槽位，也具有拥有、照顾、选择与成长的连续状态。
3. **有分量的回合制战斗**：命令、速度/状态、技能与风险反馈清楚，第一轮做到可玩、可查、可复现。
4. **文明与旅途循序展开**：生活服务、职业/任务、地理扩大和骑宠资格随剧情自然生长；首度骑宠作为中后期情绪里程碑，不强行宣称源于最早1.0。
5. **单机真正可以继续旅程**：退出、读档、重进后人物、宠物、物品、任务状态自洽；后代测试或现代存档不等于原初商业服存档原貌。

## 二、版本与创作严格隔离：三类决定

| 数据位置 | 允许引用的依据 | 对新作处理 |
|---|---|---|
| 历史事实层 | 原客户端、同期手册/攻略、被认证的后代资料 | 分版本附来源/置信度，不修改历史值来迎合设计 |
| 新作规则层 | 与经典精神相容、经过用户认可的设计 | 明标`NEW_DESIGN`；不得把虚构数值写回`V1_DIRECT` |
| 验证与生产层 | 可复核输入输出、确定性模拟、合法资产 | 引擎外保持权威状态；先做版本化测试和可回滚迁移 |

凡“原版服务端已执行过什么”仍未知，允许我们为**新作另做设计**，但必须明确是自创设定，不能打上“1999原版复原”。

## 三、建议的游戏最小可玩体验顺序（非正式生产排期）

| 门槛 | 玩家能实际做什么 | 成功判据 | 暂不纳入 |
|---|---|---|---|
| V0 情境与身份 | 在原创占位小村落看到人物和有界活动空间，走到野外 | 本地角色/坐标状态可稳定重现、来源标签明确 | 原版完整826层地图、全部NPC/全部年代 |
| V1 初战与捕宠 | 进入一场回合制遭遇、选择命令、捕获/拥有一只宠物 | 指定规则profile下命令/状态/捕获可测试 | 1999所有技能和自然结算默认数值 |
| V2 返回村落与重登 | 治疗/补给/物品操作、退出后本地重读 | 多实例读档和人宠/货品一致性 | 原商服SAAC代码或历史ACK伪装 |
| V3 逐步进入更广世界 | 条件道路、生活任务、物品/宠物成长和地理关联 | 一段清晰可体验、可回溯的任务/探索循环 | 大量后期地图/价格原样灌入 |
| V4 初次骑宠 | 玩家通过游戏内故事与训练真正第一次骑乘 | 体验节奏、条件、角色变化和视觉反馈满足共同评审 | 未认证的“最早官方骑宠前置条件”标签 |

以上`V0–V4`是讨论用阶段，不是宣称这些功能已经生产完成。

## 四、架构原则：先搭确定性骨架，保留展示替换空间

仓库既有决策 DD-016、DD-017：Python历史考古/规格和验证模型可作为**来源及比对标准**；未来有独立、引擎无关的确定性 C# 核心候选；Godot 为2D展示层**优先试验候选**，而非强制终局引擎。本轮尊重这些候选而不进行引擎锁定。

推荐结构：

`Source-tagged content/profile → deterministic game state/rules → semantic intents & results → replaceable 2D presentation → local save/version migration`

不能把原后代NPC原始参数、版权资源、地图成员当新作默认内容直接导入。引擎不成为碰撞、转移、奖励或历史谱系的权威；跨语言移植要逐条跑既有golden fixtures，防止表面能跑却换了规则。

## 五、优先完成的五项真正设计决议（未来共同确认）

1. **时代与叙事尺度**：以原始村落日常为起点，哪些文明演化元素在第一幕出现，哪些等待探索推进？
2. **宠物与人物的节奏**：捕获、培养、技能学习、首次骑乘的游戏内时机和代价。
3. **战斗复杂度**：原味交互感和现代单机可理解性之间的平衡，哪些后期扩展值得独立吸收？
4. **地理与内容复用**：哪一批地图/宠物/文本有合法可用的新资产替代，旧资料只作为研究还是可直接复用？
5. **技术原型验收**：确定性核心和Godot展示候选如何进行最小技术比较，何时批准正式生产？

**本轮不替用户给这五项定案**；这里的默认方案仅供之后共同讨论，受Stage A来源、非商用单机定位、版权和可维护性约束。
