# Taiwan 1.0 savedata R10 provenance gate

R10 continues the accepted R9 frontier using the independently hash-pinned original, without running the client or publishing original bytes. It reconstructs the bounded parent graph and computes a fixed point of reaching ESI and EFLAGS definitions. Every opaque CALL conservatively invalidates both registers. A separate syntax-only ESI candidate field ignores call clobbers and cannot establish ownership or actual preservation.

The three R9 loop branch sites are mapped to their reaching flag definitions, with bounded transformed semantic descriptors for register zero tests, comparisons and masks. Constants and relative offsets describe instructions conditionally; they do not establish actual branch outcomes, a runtime iteration bound, buffer identity or native IO. No instruction bytes, operand listing or original assets are emitted.

The nested delegate at RVA 0x491a1 is analyzed through the existing conservative R8 return-effect model. Unsummarized calls, aliases, cycles and unsupported operations remain explicit gaps. No delegate effects or parent caller resumption are admitted by this report. The existing archive custody gate and a separate strict derived-report review are required before acceptance.

Synthetic tests cover joins, unknown CALL barriers, definitions after CALL, partial register writes and comparison/mask semantics. Original reports retain all runtime and 128-byte schema admission flags as false.
