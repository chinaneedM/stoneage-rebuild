# 官方全版本宠物收录标准 R1（2026-11-15）

**项目目标：** 收集《石器时代》各个**官方实际运营发行版本**曾经真正推出的全部宠物；按原运营区域、官方运营方、具体版本、推出时间和获得方式逐一登记。不是只重建台湾1.0客户端宠物，也不收录私服独有的新增宠物。当前只开展历史证据工作；未来我们可以原创宠物，但必须与历史官方数据分离。

## 三层资料，绝不混计

| 资料层 | 说明 | 是否计入「官方曾经推出的宠物」 |
| --- | --- | --- |
| `OFFICIAL_IN_GAME_RELEASE_CONFIRMED` | 有运营方正式已开放更新、活动发放、售卖/实际获取、或具版本来源的原生游戏身份等可核证据 | **是**，按作品/地区/版本/种属/形态谨慎去重 |
| `OFFICIAL_ANNOUNCED_OR_WEB_LISTED_RELEASE_UNVERIFIED` | 官网图鉴、预告、新闻、宣传图、客户端可能预留素材，但未证明实际投放 | **否**，单列待核查 |
| `UNOFFICIAL_RESEARCH_LEAD_ONLY` / `PRIVATE_SERVER_ONLY_EXCLUDED` | 玩家攻略、私服表、私服特有宠物、无法认证的修改资源 | **否**；可留原始研究历史，但不得凭相同名字/ID自动晋级 |

新作自创宠物不属于上述历史分类，统一标识 `DESIGN_FUTURE` 并延至新游戏设计阶段。**官方展示不等于官服投放、客户端有图不等于官服开放、预告即将推出不等于已经推出。**

## 收录地区与版本

研究包含日本JSS/Hangame运营、台湾各正式运营版本、大陆各官方正式运营版本、韩国及其它有正式运营证据的地区；不设1.0或8.5上限。要追索后续正版授权的石器系列新游戏，也可以收集，但**每个产品系列单开命名空间**，绝不能将移动新作的年兽／融合宠归为1999 PC版事实。跨区不同译名要有来源原名，跨区同一物种/新形态要有身份关系证据才归并。

## 每只已证官方宠物至少建立这些字段

- **作品与地区**：产品线、运营地区、公司、具体游戏版本/活动期、第一可证推出日期（无法核实则为空）。
- **身份**：原版官方名字、别名、中文/日文/韩文原写、官方种属/ID（有证才填）；宠物系谱、物种与特殊形态/换色/进化/融合结果**分开计数**。
- **获取**：野外捕捉、任务/活动奖励、生肖限定、官方售卖、融合/进化/孵化或其它取得方式；单独保存规则/条件/是否限时，缺证则空值。
- **资源**：实际官方图鉴图、原客户端2D SPR/位图/动作方向/帧、版本SHA、是否仅网页图、版权/私人存储状态。
- **原能力**：有源的属性/成长/技能、原生效果和获取/升级条件；后期私服数字不得反推到官服。
- **发布证明**：官方日期公告/更新/活动投放/可得道具证明、原页面存档时间与图像捕获时间、原生客户端/服务器关联的原版本身份。每条结论附来源与证据等级；不宣称所有未找到资料已经不存在。

## 当前成果必须重新正确解释

PET16已有2,792条来源记录，其中2016私服/社区源、mixed25原社区存档、匿名TW1图号等 **只保留为技术研究参考，不纳入官服宠物名录**。现已有日本运营方网页124个位置、中国华义运营方网页104个位置，真实网页来源和原SHA可追；PET23确认其中日本图片38个位置的原GIF哈希。**它们是228个官方网页资料入口，绝不是228个已实装物种，也不是38个有正式官服身份的宠物。** 因为网页图尚不能单独证明实装，新官方数据登记中已确认的正式官服物种总体数量维持 `UNKNOWN`，不得虚报0种或228种。

[官方运营来源登记 JSON](../research/recovered/STONEAGE-PET-OFFICIAL-GLOBAL-RELEASE-EVIDENCE-R1.json)只放网页版本独立证据；已实装物种一栏待真实发行证据批准后填入。按源编号可查官网名字、页面快照、原图 URL/SHA，但不得因为图片名字和私服表里相同就证明同种/同版本。**统一的官方统计口径以此处为准**，原PET16继续担任未筛选技术档案，绝不能再把技术索引条数写成官服宠物数量。

## 优先批次（PET-OFFICIAL-01）

首先梳理各国官方运营版本和正式公告/补丁/活动，重点查用户指出的 **年兽、马年宠、机豹、蒙奇、海胆、肥龙**，逐个确认准确写法、地区、版本、活动/商业/融合类型以及真正推出证据。举例不是证据，亦不自动判定「机豹」与其它近似名字同一身份。其次系统覆盖台服、日服、韩服和其他正式地区，追索普通宠、限定宠、商业宠、后期进化和融合形态；再把确定名字/版本的条目关联到原图与技能属性，才扩展技术复原。后续有新的官方宠物来源，应增量列入而不重算旧版其他来源。

**结项标准：** 对已找到、可合法取得的各区域官方发行记录做带来源的可检索统计，明确已证/待证/没法取得的资料以及开启条件。**不需假装证明绝对全史100%，但更不能以台湾1.0原SPR穷举或私服数据库充数。** 宠物模块仍唯一ACTIVE，未通过整模块终审前不可转去NPC、地图、装备；Stage A7PARTIAL+2OPEN、Stage B/wiki GATED、R79暂停、整体完成率未知；旧2,709,173字节CURRENT blob `c89e0e33537990aa2132b47c40fef49a985a935c`保持不改。


## PET25｜第一次取得实装发行来源（2026-11-15）

[正式跨区各作品发行记录、24条文档证据，不是24种全球独立物种](../research/recovered/STONEAGE-PET25-OFFICIAL-RELEASE-ROSTER-R1.json)和[逐来源报告](continuity/STONEAGE-PET25-GLOBAL-OPERATOR-RELEASE-CENSUS-20261115.md)为当前官服已发行证据的**新增、优先查询入口**。旧PET24的228条日本/大陆官网条目文件是前一刻的官方网页线索快照，里面的0个已证明实装记录表示**当时的网页证据单独不能证明实装**，不是覆盖新PET25的累计官方发行事实。今后检索“正式出过的宠物”须先查PET25，检索尚待查的历史官网图像才查PET24。

PET25的24是**具体作品/地区/版本的发行文档记录**：5条大陆华义经典PC，4条韩国Netmarble不同手游，15条大陆其它正版手游。19条有原文名字或形态、5条只到大系/卡名；不能说24种世界独立宠物，也不能将《新石器时代》机械属性形态、韩国新版宠、2002华义PC宠直接等同。华义原产品文案在17173的当年镜像为同期出版物的二次存储；已列来源等级，不虚称原始华义网站原页或原客户端运行证据。新手游第一方官宣、正式补丁与发布后活动回顾也严格独立建档。

海胆系同名新服并不证明宠物可领；仅开放玄武美拉图鉴展示并不证明可得到玄武；2003原版5.0融合**机制已证**仍需寻找具体三代物种名录。NEXT仍 PET 逐官网原版本扩充、排查日韩初代原官服，技术图号从已证实际宠物身份出发关联，不反其道而行。
