# 官方 PC 版《石器时代》宠物收录标准（2026-11-19 PC-only 修订）

最新用户指令：“我们不用管手游相关的 这些内容全部删除掉 只关注PC端的”。本版执行[连续性协议§26](PROJECT-CONTINUITY-PROTOCOL-R1.md)，覆盖此前全部产品系列的收集口径。

## 当前唯一范围

**只恢复官方 PC 端《石器时代》历史版本，首先是经典原始 2D PC 游戏及其真实官方续营版本**，按中国大陆、台湾、日本、韩国和其它有运营证据的地区、官方运营主体、服务器与具体原构建分别收集。从历史最早可查证年份，依次推进至今。平台范围判定依据真实PC程序和运营部署，不依据“能在Windows运行”这一个条件；没有证据的独立新PC作品暂不并入经典版本。

现行游戏宠物图鉴、年度时序、公众检索与统计**不得收录手游、手游改编版本、仅借助模拟器/桌面登录器运行的手机服务，或与手机共用同一移动游戏服务的双端新作**。已写进旧项目记录的这类资料不再作为工作任务、在售/实装 PC 名单或正式累计数字。历史旧 Git 提交保持可追溯，不将旧留档视为有效 PC 收录。禁止将后来其它产品的名字、形态、技能、数值或发行日期套入旧PC版本。

## 实际推出证据和字段

- `OFFICIAL_IN_GAME_RELEASE_CONFIRMED`：有可定位官方PC版本的实际开放、发放、出售、任务/野外获宠或真实同服原生日志；按来源精确归类。
- `OFFICIAL_ANNOUNCED_OR_WEB_LISTED_RELEASE_UNVERIFIED`：预告、官网图鉴、宣传、客户端预载但尚不能证明已开放；仅留待核候选。
- `CLIENT_ASSET_PRESENT`：原PC客户端确有指定图像/SPR/动作字节；不能仅以图块或数字当宠物身份和实际投放。
- `CLIENT_PET_IDENTITY_CANDIDATE`：同构建本地名称/身份与图像的有据连接，仍不自动证明官服实际发放。
- `UNOFFICIAL_RESEARCH_LEAD_ONLY`／`PRIVATE_SERVER_ONLY_EXCLUDED`：同名私服、社区表或无法认证的服务端模板，不能列入历史正式PC宠物种数。

身份需区分宠物物种、外观换色、皮肤、融合/进化实体、宠蛋/道具、技能与奖励池位置；禁止凭网页位置数、同名跨服、奖励抽签总数或匿名SPR数量推导世界独立种数。每条只填写已证明的版本/地区/运营方、首次可证时点、原名/别名/ID、获取方式、原始属性成长技能、图像动作索引、SHA/CRC、原站或原二进制来源、缺口与重开条件。

## 工作与闭合门槛

优先真实免费可合法读取的原官方 PC 客户端/更新包；按字节、原文件目录、PET-ID、SPR、帧/方向、名字和技能做同源连接。旧版缺失时，后期可验证客户端只能作为分级回溯候选；不回填最初年份、服务器数值或发行证据。定点官方 PC 发放资料补证，禁止收费卖盘、私服独有宠物及不受证据支持的总种数。

PET是唯一活动模块；完成全球PC宠物来源/缺口矩阵并经过用户明确同意，才切换下一模块。Stage A仍7 PARTIAL+2 OPEN；Stage B与攻略网站尚未开启；R79 PAUSED_NON_BLOCKING；整体完成率UNKNOWN。多兆字节 `docs/CURRENT-STATE.md` 原Git blob `c89e0e33537990aa2132b47c40fef49a985a935c` 必须保持不变。原版权素材保留私人存储。
