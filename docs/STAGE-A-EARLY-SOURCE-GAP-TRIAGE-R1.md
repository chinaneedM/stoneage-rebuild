# STAGE-A-EARLY-SOURCE-GAP-TRIAGE-01｜早期村庄服务缺源可得性审计

日期：2026-10-17。阶段：Stage A 历史复原，**非**初代服务器恢复、非新游戏设计。

## 本轮目标、材料和停止线

目标不是新增一份任务模拟器，而是回答上轮五类早期第一方村庄服务为何还无法成为原版可玩事务，以及继续检索能否在现有材料里获得**可认证的新字段**。基础为日本 JSS 官方手册 2001-04-18 实际网页存档的派生来源合同、台湾 v1 原客户端的通用可视消息结构与当前九系统 Stage A 审阅。它们有不同版本、不同来源角色，**不能跨层等同**。

本轮审查了仓库既有已固定 Git blob 和限定公开搜索。检索无可认证、同版且能填补具体缺口的新一手字段；这不意味着原始服务器记录或同年代网页在全球不存在，也不意味着存档 URL 的阅读器错误就是史料缺失。未取得新原商业服务端、原始游戏运行轨迹或 JSS1999 完整样本。可审计的逐项字段、精确检索词和标志见 `research/recovered/STONEAGE-STAGE-A-EARLY-SOURCE-GAP-TRIAGE-R1.json`。

## 五类服务：保留事实，阻止猜测

| 服务 | 已有证据能说什么 | 阻塞原版复原的具体字段 | 必须验证的重开材料 |
|---|---|---|---|
| 记录点 | JSS2001说明首次供品及重新登录采用记录点 | 供品ID/数量、原始事件、写入ACK及重登轨迹 | 匹配发行版本的NPC/服务脚本或成对存取轨迹 |
| 长毛象公车 | 手册所述三村分组、停站3分钟、乘客上限4、乘车不遇敌 | 实际相邻站点、收费/票价、调度/遇敌关闭语义 | 同代官方线路/票价或同版服务器运行记录 |
| 医疗与宠物服务 | 医疗、付费学技能、宠物回购等类别 | 各村NPC、技能目录与价格、实际状态变化 | 原版菜单及交易数据、可定位年份的服务列表 |
| 送货和矿石工作 | 官方手册确有这类工作示例 | 原版任务物品、对话、进度旗标与报酬 | 同年代原版任务脚本/完整原始操作证据 |
| 地面物品消失 | 手册描述普通放置物品在未定时长后消失 | 具体时间、时钟来源、服务端清除及物品例外 | 同版带时间的追踪或明确第一方数值 |

**不能将“找不到能填的字段”变成0费用、默认秒数、原版任务ID、全村通车、成功存档、已执行原版场景。** 后代 recovered25 世界/NPC/价格及现代参考磁盘保存继续按原限定可用，但没有初代归属证明。

## 实际检索及证据强度

- 限定入口包括官方 `titan.co.jp/stoneage/manual02.html` 的既知存档、2000–2001年 JSS / StoneAge / 石器时代相关日中文关键词、村落公车及记录点。部分网络结果是当代交通、汽车或新 IP，与1999–2001年原游戏无关，已排除。
- 对 `https://web.archive.org/web/20010418083149id_/http://www.titan.co.jp/stoneage/manual02.html` 的本轮公开阅读器直接打开失败：只能记为**当前接口未读通**。既有 Git 中的旧派生正文/原始哈希仍可使用，不能被这次失败撤销，也不能假装已新下载原始字节。
- 没有从其它搜索结果中证实早期客运收费、相邻边、供品ID、服务价目、矿石报酬或地面消失秒数。此结论**仅限本轮检索和当前持有的固定来源**，不是全网缺席证明。

## 九系统复原安排

本包将五类服务的具体缺失字段标记 OPEN_EVIDENCE_LIMITED 并记录独立重开触发。若无版本可归属新资料，五类服务停止进一步假定或研发；不再沿本分支增加后代NPC字段或 savedata R79 辅助函数。未来若找到一份真实原版服务器/任务/录包，**只重开对应命名的业务规格**，先核来源和版本，再改规则。

最有价值的下一项是 **STAGE-A-JOINT-REVIEW-DECISION-01**：用 `docs/STAGE-A-CONSOLIDATED-REVIEW-R1.md` 与本包缺源清单向用户提交九系统7 PARTIAL、2 OPEN／七条代表体验／五类阻塞的联合审阅；由用户决定是否接受“有界历史复原+明确不可恢复部分”作为阶段收束，或针对某项仍有新资料的缺口继续 Stage A。**当前还没有联合验收，Stage B 仍受门禁。**

本包未恢复新的具体原版NPC、商品、奖励、原始服务端确认、地图内容或可玩进程；通过的任何审查测试都不能当作恢复百分比。
