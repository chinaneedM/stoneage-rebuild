## 为什么这是目前更优的选择

反复追同一来源里已经明确没有的原NPC商品、任务脚本或无同版对应关系的后代参数，不能增加历史真实度，只会拖慢项目从“了解石器是什么”走向“做好新的石器”的准备。现有资料已经足以让我们讨论世界结构、战斗宠物核心体验及现代单机架构，同时明确知道**哪些只能设计、不能冒称1999/台湾1.0**。未来取得真实同版证据，按具体业务领域重开并比较，不推翻其它已固定来源。

## 新证据重开流程（不可因研究检查点关闭而丢失）

1. 准确登记来源类型、日期、地区、对应客户端/服务端构建、文件指纹及合法取证路径；
2. 显式比对 `V1_DIRECT` / `EARLY_LINEAGE` / `LATER_RECOVERED` / `MODERN_SYNTHETIC` / `NEW_DESIGN`，不跨层推断；
3. 指向具体系统族/规则/体验：例如早期地图脚本、物品价目、原商服持久化ACK或原版实际图形调用；
4. 为原有判断追加版本化修订、反例与测试；不删除旧证据和历史失败记录；
5. 若改变新作设计，先分析对兼容、存档、体验的影响，再做独立设计决策，不把史实与创作混在一起。

在新来源不存在时不恢复 R79 深层旧辅助函数、不给后代数据强加初代身份、不扩充无分母进度统计。
