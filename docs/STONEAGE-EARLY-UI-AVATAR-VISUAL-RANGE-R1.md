# ORIGINAL-UI-LOGIN-AVATAR-REVIEW-01：2001位图类别、人物/宠物图像及登录出处双证据

新查得一份**确切于2001-06-14发表**的玩家技术资料：《stonepic的图片编号》，发表于17173石器专区，作者寻梅子・古月，网页 https://news.17173.com/z/stoneage/content/2001-6-14/n84_511.html 。文章给出地形/NPC/道具/宠物照片/人物照片/人物动作/GM动作/宠物动作及UI图像等数字号段。这是2001年**玩家亲历记录**，不是JSS原始正式开发文件，也没有指定与当前台湾1.0光盘完全同构建。必须将它和**台湾1.0原客户端确实存在的ADRN编号**逐号比较，绝不能把“2001玩家给出的用途标签”直接升级为台湾1.0原版图像身份。

另查17173旧新手指南（https://news.17173.com/z/stoneage/guide/14.htm，页面现无明确发表日期）：描述更新公告栏、WGS账号与服务器选择、双人物角色槽位、12个候选人物外观与调色/朝向确认、面容/能力/属性/出生地、地图/宠物/道具/NPC窗口操作。这是**历史使用者界面流程文字**，不是证明当前TW1.0登录窗口真实按钮坐标、具体png/bitmap或准确首发角色数。台湾1.0原客户端`CreateNewChar`确有13个字段，包括`body_image_id`与`face_image_id`，但**当前没有登录/选角实际渲染调用链或已认证原始同版截图**。

新脚本`tools/stoneage_early_ui_bitmap_range_audit.py`使用当前已验证台湾1.0原ADRN gzip索引，对上述2001玩家号段逐号查原始位图记录。输出为机器来源检查点，不存原版权像素，不把后期大陆界面复制为初代台湾界面。

特别重要：2001作者说其图库编号**126766**是“大陆版登录画面”的图片，它在本项目台湾1.0资源编号上界125995之外；因此不可从这段文字伪造“台湾1.0已经恢复出登录图”。2001作者还给出125996以上后来节庆装饰/操作界面等号段，必须保留后续版本分界而不是合并进原盘索引。原版可见画面/宠物物种/实际点击触发关系仍OPEN。

本工作单元以真实出处+原盘bitmap membership校验结果、明确残缺/版本差异为交付，不渲染图片也不搭建网站、新游戏。若无2001/台湾1.0同源截图或资源选择链则不无限扩大归类。
