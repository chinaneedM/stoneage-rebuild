## Native gate

GNU99 O0/O2 with nonrecovering UBSan compares original helper returns and every
physical table value against a strict independent integer-initializer parser and
lookup oracle. The parser permits bounded integer expressions/nested arrays,
rejects identifiers/calls/noninteger values and int32 overflow, and preserves
static declared length separately from initializer length. Table readback checks
original C representation, including all zero-filled rows and duplicate rows.
It is distinct from execution of a historical inactive caller.

Equipment cases cover each physical base key, missing keys, index-1/0/1, belt
absent/present and categories-2/-1/0..6, excluding only category5 that reaches a
matching lookup row. Bismarck present-belt branch returns current image before

is independently verified from the original item enum. New-ride pet lookups cover
each pet/missing keys, every mask0..2^width-1 and negative masks-1/-2. Player keys,
negative/outside ride coordinates and every selected table field are covered.
