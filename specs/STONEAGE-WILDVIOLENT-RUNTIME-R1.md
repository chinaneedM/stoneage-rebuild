## Ordered action and randomness

Base status and the shared WEAKEN/BARRIER/NOCAST overlay visit the actor before
dispatch. Sleep, Barrier, death, incomplete input and confusion's command
rewrite suppress specialized execution. Specialized count RNG supplied on a
suppressed path is rejected; confusion may instead consume ordinary attack
RNG. A missing count bundle for an actual specialized action is rejected.

`WildViolentRolls` provides an explicit RAND(3,10) witness at dispatch, before
target-list/initial retarget. Its count fixes the number of potential hit
bundles; skipped bundles contain only None fields. Each later hit resets to
the original submitted target before dead/unoccupied-target adjustment.
There is no AttackCrazed pool preselection. Count is still consumed if there
is no opponent; no hit RNG is consumed on that path.

Dodge uses the original defender and the additive HIGH(COM3) modifier before
Guardian. Guardian then selects the damage defender. AttackSeq's critical,
guard and minimum-damage decisions precede the float32 division; positive
truncated zero becomes one. Existing DamageSub reaction, ride split, wakeup
and ultimate seams settle each divided hit. A FALSE hit continuation alone
does not stop later hits, but actor death or exhaustion of opposite-side
targets does. The modifier is cleared before the shared final counter chain.
Specialized submissions do not start/join an ordinary combo. After execution
the ordinary ATTACK command participates in proved counter timing.

Unused per-hit RNG is rejected, including live-target retarget draws,
critical/damage draws on a dodge, dodge draws against a guarding original
target, unused guard/minimum/ultimate draws, and draws after early termination.
Validation is limited to this specialized path; accepted ContinuationAttack
and AttackCrazed contracts remain unchanged.
