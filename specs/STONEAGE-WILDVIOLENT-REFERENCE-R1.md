# WildViolentAttack conditional source reference R1

Evidence role: **LATER_RECOVERED**. This is not Taiwan-v1 membership or an
original compiler/binary identity. Ordered runtime remains **OPEN**.

## Proven source scope

Clean pinned gavin, iriselia and Bismarck descendants are independently checked
with active version headers and actual command enum compilation. The resulting
commands are 2018 / 2018 / 2017; source pet-skill macro is 540. Recovered data ID
541 is a separate namespace. The reconstruction retains symbolic commands
under DD-019 and assigns neither number to a recovered binary.

The callback writes command, target and C_OK before reading OPTION. It has no
actor-kind rejection. Attack and defense markers independently replace work
powers with fixed strength/toughness plus a truncated float32 delta; absent
markers preserve their preceding work powers. Failed float scans retain the
shared float local, initialized to 0.01 and divided by 100 on each found marker.
Attack is processed before defense, regardless of marker order in OPTION.
Only HIGH COM3 is changed; LOW is preserved and is not populated with an array
index. Gavin/iriselia reject NULL but accept empty strings. Bismarck rejects an
empty string with strcmp; NULL dereferences and remains outside admission.

The original signed HIGH macro left-shifts its value. Negative dodge modifiers
and values above 32767 are undefined inputs; synthetic -10 and 32768 fixtures
must produce expected UBSan diagnostics. Do not substitute a presumed x86
wrapping result for a defined portable reference.

## Encoding boundary

The preserved source files have UTF-8 marker text but use fixed byte offsets
of three after attack/defense and two after dodge. Compiling the actual callback
with UTF-8 execution literals leaves the attack/defense scanner on `%` and the
dodge scanner inside a multibyte character. Failed scans do not mean zeroing
the float local. CP950 OPTION bytes also do not match UTF-8 literals.

An explicit GCC CP950 execution-charset build supplies two-byte markers and
allows ASCII numeric scans at those offsets. Its result is a **conditional
reference**, not evidence that the preservation binary used that compiler
setting. The probe separately requires strict CP950/Big5 data decoding and
parsed-value convergence. Even successful convergence does not resolve the
original compiler charset. OPTION bytes are treated as bytes during strstr;
the API does not silently transcode them.

Finite bounded decimal scanf values round directly to binary32, including
exact halfway cases; nondecimal/NaN/infinite/incomplete exponent/overflow
domains fail closed. Signed int32 product conversion and final power addition
are separately checked. Runtime admission will need actual full metadata and
OPTION hash, not merely a callback spelling or synthetic sample.

## Action/physical seam

In the unsuppressed non-bow/opposite-side domain, action dispatch draws
RAND(3,10), stores this as the damage divisor and copies HIGH COM3 into the
additive dodge modifier before target-list construction and initial retarget.
The non-bow list contains twenty copies of the submitted target, without
AttackCrazed's random candidate preselection. Active same-side limiting differs
between profiles and is outside this reference's admitted domain.

The common physical loop rewrites command to ordinary ATTACK, performs each
hit, and resets later COM2 to its original target before TargetAdjust. A FALSE
hit continuation result does not itself stop subsequent hits: the last result
controls the final counter chain, limited to five. Death/count/target/side
termination still applies. The dodge modifier is added to defender dodge
probability before clamping; positive values increase evasion. It is cleared
before final counters.

Positive damage is divided using float gDamageDiv after AttackSeq and Guardian
selection, before DamageSub reaction/ride/ultimate settlement; truncated zero
becomes one. Nonpositive damage is unchanged. A float32 reference is necessary:
large signed int32 damage can differ from Python binary64 division. The new
reference does not alter the accepted ContinuationAttack runtime, settle HP,
invent random draws, or claim status/suppression/counter runtime acceptance.
